\title{Thinking in Pretraining:\\ Thirty Runs of Negative Results, and the Instruments That Produced Them}
\author{}
\date{\today}

\begin{document}
\maketitle

\begin{abstract}
We ask whether a language model can learn, during pretraining and without supervision of content, to write a short thought that makes the text it is about to predict more likely. A 0.6B model trained from scratch emits a free-form thought at fixed anchors; the thought is spliced at overlapping integer positions and the next $k$ real tokens are scored with it and without it in the same forward pass, so a thought's value is a measured counterfactual in nats. Thirty-four runs and roughly $5$B thinking-mode tokens later, the answer at this scale is no, and the interesting content of this paper is \emph{why}, measured rather than argued. Four results carry it. (i)~\textbf{The reader is not the bottleneck}: a true $12$-token hint drawn from inside the scored window is worth $+4$ to $+11$ nats, the same tokens shuffled are worth $0$, and a hint drawn from beyond the window---the target we supervised for three billion tokens---is worth $-1.6$. (ii)~\textbf{Every content the model can actually produce at inference is worse than an empty slot}: against content-free filler on the same weights, its own thought loses at every length from $2$ to $12$ tokens, on seven checkpoints under four different reward shapes---by $0.1$ to $0.9$ nats depending on the run and the length, and by $0.81 \pm 0.08$ on the last checkpoint of the programme. (iii)~\textbf{The writer can forecast but not free-running}: with the true prefix teacher-forced into the slot it predicts the next true token $30\%$ of the time against a $41\%$ clean-text ceiling, and $6\%$ when it writes the prefix itself---the regime every run trained in was never the regime any run samples in. (iv)~\textbf{Reader miscalibration was real and is fixable, and it is not enough}: training the reader only on one unselected thought of the model's own halved the cost of thinking ($-2.45 \to -1.17$ nats) and then saturated, with order-borne value never once positive. We also report the mistakes that these instruments caught in our own work---bf16 parameters that froze half the network, a learning rate that destroyed the base, a supervised target the reader values below silence, an offset lottery that made the target unlearnable by construction, and thought positions one step out of register, worth $0.85$ nats by themselves---because each was invisible in the training curves and each cost days. On the final checkpoint the zero-shot suite agrees with the held-out probes and adds the plainest artefact we have: a thought at inference costs $1.4$ macro points against the same weights in clean mode ($p = 4\times10^{-4}$ over $4{,}000$ paired examples), and the thought being scored is $258$ distinct strings across those $4{,}000$ examples---one of them emitted at $1{,}083$ of them. What the writer learned is a register, not a forecast. The design, the probes and the falsification record are the contribution; the mechanism is not yet one.
\end{abstract}

\section{Introduction}

Standard pretraining gives a model one forward pass per token. Some tokens are easy and waste it; some sit at the end of a chain of implicit reasoning and exceed it. The idea we test is the obvious one: let the model write a few ordinary vocabulary tokens first---a \emph{thought}---and then predict the real text with that thought in context. Nothing supervises what a thought should say. It is credited only by what it does: the discounted log-likelihood of the true continuation with the thought, minus the same quantity without it, computed in the same forward pass so the baseline is free and exact.

The appeal is that this is unsupervised, needs no task data, and asks the model for the one thing next-token prediction never asks: commit to something about how the text will develop, before seeing it. The difficulty, which we did not appreciate for many runs, is that a thought is a function of the context, so it cannot carry information the context lacks; it can only pay by (a) being a correct forecast the reader can exploit, or (b) buying serial computation. We now have measurements of both channels, and both are closed at this scale: the forecast is too rarely correct to be worth its confident errors, and the computation channel---measured with content-free filler in the same slots---is worth approximately zero and still beats what the model writes.

This paper is therefore a negative-results paper with a positive methodological core. The core is a set of cheap, zero-update probes that answer questions a training curve cannot: where in the future the value of a hint lives; what the model's own thought is worth at inference with nothing selected; what an \emph{empty} slot is worth in the same place; how much of a thought the model gets right, teacher-forced versus free-running; and whether the slot's geometry is costing anything. Every claim below is one of those measurements, on held-out text, with the number the model would actually get---never a best-of-$R$ winner, which inflates by construction.

\paragraph{Contributions.}
(1)~A precise counterfactual objective for thinking during pretraining, and a training procedure (mixed supervised/reinforcement anchors in one sequence, compulsory thinking, $R$ rollouts with paired baselines) that is stable, never collapses the base, and costs about $4\times$ vanilla per token.
(2)~Six instruments (Section~\ref{sec:instruments}) that localise the failure, including the \emph{filler floor}: the value of extra positions with no content, which we argue should be the reporting bar for any work of this kind, and which no checkpoint of ours has cleared.
(3)~A falsification record: four negative results (Section~\ref{sec:negative}) each replicated across reward shapes, supervision fractions, thought lengths and base maturities.
(4)~A catalogue of our own mistakes and the measurement that caught each (Section~\ref{sec:mistakes}), including a numerical-precision failure that silently freezes half of a network's weights under plain AdamW.
(5)~The conditions under which we think the idea can still work, stated as quantities rather than hopes (Section~\ref{sec:whatwouldwork}).

\section{Method}
\label{sec:method}

\subsection{Setup and notation}

Let $t_{1:T}$ be a training sequence ($T=1024$; $2048$ for the longer-thought geometry). \emph{Anchors} sit at a fixed stride: one every $k$ tokens from position $64$, so that reward windows tile the sequence and never overlap ($N=14$ anchors at $k=64$). In the first two phases of the programme placement is therefore capacity, not policy; Section~\ref{sec:budget} describes how the model takes over placement under a budget in the third. Earlier designs placed anchors by an entropy trigger with a context floor (Appendix~\ref{app:previous}); the fixed stride replaced them because it makes every mask, position and row index a per-run constant, and one compiled graph serves every step.

At an anchor $n$, the model generates a thought $\thought = (\thought_1, \dots, \thought_L)$ of $L$ ordinary vocabulary tokens. Write $\ctx = t_{1:n}$ for the context and $\win = t_{n+1:n+k}$ for the next $k$ true tokens, the \emph{reward window}. One set of parameters $\theta$ plays two roles:
\begin{align}
    \text{the \emph{writer}:} \quad & \policy(\thought \mid \ctx) = \prod_{i=1}^{L} \policy(\thought_i \mid \ctx, \thought_{<i}), \\
    \text{the \emph{reader}:} \quad & \reader(\win \mid \ctx, \thought) = \prod_{j=1}^{k} \reader(t_{n+j} \mid \ctx, \thought, t_{n+1:n+j-1}).
\end{align}
The writer produces the thought; the reader consumes it; both are the same transformer. In the implementation, thoughts live in a spliced buffer appended to the sequence: window tokens attend to their thought through an additive attention mask, all other real tokens mask every thought out, and thought blocks never see each other. Thoughts are therefore \emph{ephemeral}: only the $k$ tokens of the reward window read the thought, which keeps windows independent and keeps a bad thought from contaminating the rest of the sequence.

Generation is deliberately unconstrained (\emph{free-form}): the writer samples from the full vocabulary with top-$512$ truncation, temperature $1.0$ and a frequency penalty. We impose no vocabulary allowlist and no format. The closing token \tend{} is an ordinary action: a thought may stop after $L_{\min}$ tokens and must stop at $L$.

\subsection{Objective}

The ideal objective at an anchor is the marginal likelihood of the true window,
\begin{equation}
    \log \reader(\win \mid \ctx) = \log \sum_{\thought} \policy(\thought \mid \ctx)\, \reader(\win \mid \ctx, \thought),
\end{equation}
whose intractable sum we lower-bound by sampling thoughts from the writer:
\begin{equation}
    \mathcal{J}(\theta) = \E_{\thought \sim \policy(\cdot \mid \ctx)} \big[ f_\theta(\thought) \big],
    \qquad
    f_\theta(\thought) := \log \reader(\win \mid \ctx, \thought).
    \label{eq:objective}
\end{equation}
The bound is tight when the writer equals the posterior $\reader(\thought \mid \ctx, \win)$: the distribution over thoughts given knowledge of how the text continues. The writer conditions on the past only, so training squeezes it toward the best past-conditioned approximation of a future-aware posterior. This gap is the definition of useful thinking: the model must predict which deliberation will pay off before it knows the answer.

\subsection{Long-horizon discounted gain}
\label{sec:gain}

The scalar that drives all learning about thought content is the \emph{discounted counterfactual gain}
\begin{equation}
    \gain(\thought) \;=\; \sum_{j=1}^{k} \gamma^{\,j-1} \Big[ \log \reader\big(t_{n+j} \mid \ctx, \thought, t_{n+1:n+j-1}\big) \;-\; \log \reader\big(t_{n+j} \mid \ctx, t_{n+1:n+j-1}\big) \Big],
    \label{eq:gain}
\end{equation}
the improvement the thought causes in the log-likelihood of the true window, term by term, relative to the same model without the thought. The no-thought pass is computed anyway for ordinary NTP, so the counterfactual baseline is free, and it removes the intrinsic difficulty of the position: a hard window has low log-likelihood with or without the thought, and $\gain$ isolates the causal contribution. We use $k = 64$ and $\gamma = 0.97$ ($k=128$ for the longer-thought geometry), giving an effective horizon $\sum_{j=1}^{k}\gamma^{j-1} = (1-\gamma^{k})/(1-\gamma) \approx 28.6$ tokens: credit concentrates where the thought's causal influence is strongest while still extending far beyond the thought itself.

\paragraph{Two losses, two questions.}
Equation~\eqref{eq:gain} is what separates this objective from NTP, so it is worth stating what each measures. The NTP loss scores the local surface: the next token given the visible past. The gain scores \emph{anticipation}: it is nonzero only for content, committed to before the window is seen, that changes how well the model predicts the way the text develops over the effective horizon. A thought can therefore earn reward only through information about the \emph{evolution} of the text---the intermediate step of a derivation, the entity an argument is converging on, the structure of what follows---and never through fluency, plausibility, or local pattern completion, all of which the counterfactual subtraction cancels. In this precise sense the reader term trains prediction while the writer signal trains anticipation, and the two share one set of weights: the hypothesis under test is that representations shaped by the second question improve answers to the first.

\paragraph{Why the horizon must exceed the thought.}
Consider the myopic version of Eq.~\eqref{eq:gain} with $k \le L$ and no discount. The gain is maximized by any $\thought$ that makes $\win$ certain, and the verbatim copy $\thought = \win$ achieves this whenever the reader can learn to transcribe---an easy skill for an attention model. The optimum of the myopic objective is therefore \emph{copying, not thinking}, and Appendix~\ref{sec:failures} shows our $k=8$ runs discovered exactly this. With $k = 64 \gg L = 16$ the copy strategy cannot cover the window, and---more fundamentally---the writer does not know $\win$; a copy-like thought can only transcribe the model's own best guess, which the next mechanism prices at zero.

\subsection{The training procedure}
\label{sec:procedure}

Every design in Appendix~\ref{app:superseded} shares one structural weakness, and eighteen runs were needed to see it. The model was always allowed to \emph{decline}. A learned gate decided whether to open a thought at all, and because a thought costs tokens and a bad thought costs likelihood, the cheapest available policy was to stop thinking: in every reinforcement run $p(\tstart)$ fell through many orders of magnitude to the exploration floor. Where the gate was held open, the same evasion reappeared one level down---the model made its thoughts \emph{inert}, so that $\gain$ and $\gain_{\mathrm{shuf}}$ rose together and their difference contracted to zero from either side. A thought that does nothing is never punished. The procedure below removes both escapes.

\paragraph{Anchors carry supervision and reinforcement in the same sequence.} Anchors are placed every $k$ tokens. Each is assigned, by coin, to one of two roles. A fraction $\rho = \tfrac14$ are \emph{supervised}: the thought slot is filled with the true continuation from beyond the scored window, teacher-forced at a jittered length, and the model is trained to produce it by ordinary cross-entropy. The remaining $\tfrac34$ are \emph{reinforcement} anchors: the model writes its own thought and is scored on what that thought does. Both kinds occupy identical \tstart{}\ldots\tend{} slots a few dozen tokens apart in one sequence. This matters more than it appears: in the previous designs (Appendix~\ref{app:previous}) the two channels lived in \emph{separate micro-batches}, so the model never saw a supervised thought and a self-written one in the same context, and ``write thoughts that look like the supervised ones'' had to travel through the weights across batches rather than being visible as a within-context pattern.

\paragraph{Thinking is compulsory.} There is no learned gate. At every reinforcement anchor the model must emit a thought of at least $L_{\min}$ tokens. An inert thought is therefore no longer free---it scores $\gain \approx 0$ and still pays its per-token price, which is strictly negative---so the policy cannot buy safety by saying nothing. Removing the gate costs an observable we valued (\emph{when} to think is no longer learned) and we regard that as the correct trade: a question the model answers by refusing to participate is not a question worth asking of it yet.

\paragraph{The reward is the raw counterfactual gain.} Runs 13$'$--17 rewarded the shuffle-corrected gain $\gain - \gain_{\mathrm{shuf}}$, which pays only for what token \emph{order} buys. That correction was introduced to close the register exploit (Appendix~\ref{sec:failures}), and it did---but it also made the reward almost unwinnable, because the order-borne component of an immature policy's samples is a small negative constant (Appendix~\ref{sec:run17}). With the supervised channel now holding the policy on the manifold of real future text at every step, the exploit it defended against is closed by construction, and the reward reverts to the quantity the objective actually names: did this thought make the true continuation more likely.

\paragraph{The shuffle survives as an instrument.} We continue to score a token-shuffled copy of each winning thought, at the cost of one forward pass, and it never enters the loss. Raw gain is winnable by topic priming---putting relevant vocabulary in context, which a bag of words does equally well---so without the minimal pair we could not distinguish priming from anticipation, and that distinction \emph{is} the scientific claim. Demoting the shuffle from reward to instrument is the single most consequential change here: it is what lets the objective be winnable while keeping the measurement honest.

\subsection{Search width: $R$ rollouts with paired-sample baselines}
\label{sec:rollouts}

A single sampled thought per anchor is the binding choice of the earlier designs: the audit prices genuinely informative thoughts correctly, at $+1.7$ nats, but an immature policy proposes one well under $1\%$ of the time (Appendix~\ref{sec:run13obs}), so the mean never leaves zero. We therefore draw $R$ rollouts $\thought^{(1)},\dots,\thought^{(R)}$ per reinforcement anchor (plus a greedy row, retained as a length diagnostic), score each once, and use them two ways.

\textbf{Paired-sample baselines} \citep{kool2019buy}. With $r_i = \gain(\thought^{(i)}) - \lambda L_i$ the raw gain of rollout $i$ net of its token price, the advantage is
\begin{equation}
A_i \;=\; r_i \;-\; \frac{1}{R-1}\sum_{j \neq i} r_j ,
\label{eq:paired}
\end{equation}
so each rollout is baselined by the mean of its siblings \emph{at the same anchor}. This is unbiased, costs no extra forward pass, and---unlike cross-anchor whitening---removes the anchor's intrinsic difficulty, so an easy position no longer makes all of its rollouts look good. By construction $\sum_i A_i = 0$ at every anchor. Advantages are then standardised across the reinforcement anchors of the micro-batch, clipped, and negative advantages are damped by a factor $4$ (a lesson of Appendix~\ref{sec:run13obs}: undamped negatives pull the writer toward silence faster than positives pull it toward anything).

\textbf{Best-of-$R$ selection.} The anchor's winner $\arg\max_i \gain(\thought^{(i)})$ is the content spliced into the training buffer, so the reader is trained on it and the policy gradient acts on it with the winner's own paired advantage. One token-shuffled copy of the winner is scored in a further pass; it enters no loss (Section~\ref{sec:procedure}) and is the instrument behind every claim about order-borne value below.

\textbf{A reporting discipline this forces.} Best-of-$R$ inflates the selected rollout's apparent value for selection reasons alone: on pure noise, $\E[\max_i - \operatorname{mean}_i]$ is $+0.57$ standard deviations at $R{=}2$ and $+1.42$ at $R{=}8$. We therefore report $\gain$ as the \emph{mean over rollouts}, the $R{=}1$-equivalent quantity that stays comparable across runs, and record the winner separately; $\gain_{\mathrm{shuf}}$ is measured on the winner. Two differences can then be formed and neither is unbiased: $\gain - \gain_{\mathrm{shuf}}$ compares the mean rollout with the winner's shuffle, two different thoughts, and is biased \emph{negative} because the winner's shuffle inherits the winner's topical advantage; $\gain_{\mathrm{win}} - \gain_{\mathrm{shuf}}$ compares the winner with its own shuffle and is biased \emph{upward}, because among $R$ rollouts the winner is selected partly for a lucky order. The unbiased instrument is the shuffle of a \emph{non-selected} rollout---what runs 16--17 scored for every rollout---at the cost of one further pass; the pilots below did not score it, and the programme does.

\subsection{The one gradient pass}
\label{sec:losses}

Differentiating Eq.~\eqref{eq:objective} gives
\begin{equation}
    \nabla_\theta \mathcal{J}
    = \underbrace{\E_{\thought}\big[ \nabla_\theta f_\theta(\thought) \big]}_{\text{reader term}}
    + \underbrace{\E_{\thought}\big[ f_\theta(\thought)\, \nabla_\theta \log \policy(\thought \mid \ctx) \big]}_{\text{writer term}}.
    \label{eq:gradient}
\end{equation}
Both terms, and the ordinary NTP loss, are computed in one forward--backward pass over the spliced buffer as three weighted cross-entropy sums over the same hidden states. \emph{Clean NTP} acts on every real token with weight $1$: the vanilla objective is unchanged. The \emph{reader term} acts on the window rows of every thinking anchor, discounted by $\gamma^{j-1}$ along the window, with weight $0.3$; it teaches the model to \emph{use} whatever sits in the thought slot, supervised or self-written. The \emph{writer term} acts on the thought rows: at supervised anchors it is plain cross-entropy on the true continuation (weight $1$, never decayed); at reinforcement anchors it is the score-function estimator with the winner's paired advantage of Eq.~\eqref{eq:paired} as a signed per-row weight (weight $0.15$, ramped in over the first $600$ steps and constant thereafter). The relative weights encode the position of Section~\ref{sec:role}: imitation is the teacher, reinforcement is the explorer, and neither is ever switched off.

\subsection{Splicing thoughts at integer positions}
\label{sec:splice}

Thought tokens need positions, and the choice is not cosmetic: our first scheme placed thoughts at fractional offsets inside $(n, n{+}1)$ and made perfect information worth $-1.3$ nats (Appendix~\ref{sec:positions}). The adopted scheme is \emph{integer splicing}: real tokens keep their standard positions $1,\dots,T$; the $i$-th token of a thought anchored at $n$ receives position $n + i$ (integers continuing from the anchor), overlapping the positions of the upcoming real tokens. The overlap is harmless---attention masks keep the streams separate, and rotary attention only sees relative offsets---while the thought sits at the natural distance from both its context and its window. Real-token geometry is untouched, so thinking remains positionally invisible to the main sequence.

Every evaluation is \emph{position-matched}: any comparison between thought variants (oracle, sampled, random, filler) places all variants at identical positions, so measured differences are differences of \emph{content}, never geometry. The oracle test is now run before and after every training phase as standard calibration.

\section{The instruments}
\label{sec:instruments}

Every failure in this project was invisible in the training loss and visible in one of the following measurements. All are zero-update, run on held-out text, and cost minutes to an hour of CPU beside the accelerator.

\paragraph{The counterfactual gain (in training, every step).} For each anchor, the discounted log-likelihood of the next $k$ true tokens with the thought minus the same without it, both read off one forward pass over the spliced buffer. We log it for an \emph{unselected} sampled rollout ($g_{r_0}$), for the greedy thought ($g_{\mathrm{spec}}$, what a user would get), for the best of $R$ (reported only as a selection diagnostic), and for a token-shuffled copy, whose difference from the unshuffled one is the order-borne value $\mathrm{ob}_0$.

\paragraph{The oracle-offset probe (\texttt{probe\_oracle\_offset.py}).} Splice a \emph{perfect} $12$-token hint taken from $o$ tokens ahead of the anchor and score the window. It answers where the value of a hint lives, and it is what showed that our supervised target lay outside that region entirely (Section~\ref{sec:offsetprobe}).

\paragraph{The think-mode probe (\texttt{probe\_thinkmode.py}).} The model writes its own thought at every anchor of a held-out sequence, sampled and greedy, nothing selected, and we report the change in window cross-entropy. This is the headline number of the project and the only one that corresponds to using the model.

\paragraph{The filler floor (\texttt{--pause-len}, and the same probe with filler).} The identical slots filled with content-free tokens, on the same weights. It measures what the extra positions alone are worth---the pause-token effect of \citet{goyal2024think}---and it is the bar a thought must clear to be doing anything as \emph{content}. We recommend it as standard practice: a paper reporting that thinking helps, without this control, has not separated thinking from compute.

\paragraph{The draft-length probe (\texttt{probe\_draft.py}).} The model's own greedy thought truncated to $m \in \{2,4,6,8,12\}$ tokens, against filler of the same length and against the true tokens of the same length, plus the token-level agreement between the two. It converts "our thoughts hurt" into a curve in $m$ and separates a wrong \emph{tail} from a wrong \emph{start}.

\paragraph{The teacher-forced-slot probe (\texttt{probe\_tfslot.py}).} Positional agreement with the true continuation under three conditions on the same anchors: clean text (the ceiling), the true prefix teacher-forced inside the thought slot, and the model's own free-running thought. It splits a broken slot from exposure bias.

\paragraph{The slot-position probe (\texttt{probe\_slotpos.py}).} The same buffer scored twice, changing only the position vector, which tells us what the slot's geometry costs (Section~\ref{sec:slotpos}).

\paragraph{The held-out ruler and the paired benchmark.} Cross-entropy of every checkpoint on disjoint documents from the same three sources, scored by cron during training---the price side of the ledger---and zero-shot likelihood benchmarks scored per example so that thinking and clean modes can be compared on the same weights, and both against the token-matched \emph{and} compute-matched vanilla rungs.

\label{sec:negative}

\paragraph{N1. The reader is not the bottleneck.} Figure~\ref{fig:hintvalue}. After phase A the model converts a true $12$-token hint into $+8.9$ nats when the hint comes from the tokens immediately ahead, $+6.3$ at $16$ tokens ahead, $+4.0$ at $32$, $+1.5$ at $48$ and $-1.6$ from beyond the scored window; a vanilla model that never saw a thought gets $+8.1$ from the immediate continuation and nothing from anywhere else. The same true tokens \emph{shuffled} are worth $-0.1$. So the reader is strong, order-sensitive, and generalises to hints it was never trained on. Whatever is wrong is on the writing side.

\paragraph{N2. Every content we can produce at inference is worse than an empty slot.} Figure~\ref{fig:belowfiller} and Figure~\ref{fig:ledger}(b). On held-out text, with the model writing its own thought: run 21 $-1.99$ nats, run 24 $-2.45$, run 25 $-1.17$, run 27 $-0.86$, run 30 $-2.25$, run 34 $-1.50$ (greedy; sampled is worse in every case). Content-free filler on the same weights is $-0.74$ (run 25 @900) and $-0.08$ (run 26, trained with filler). The gap is $-0.43 \pm 0.13$ against run 25's own checkpoint, $-0.36 \pm 0.15$ against run 27's, and $-0.64 \pm 0.12$ against run 30 @600's, each on the $n=465$ windows the two conditions share. Only run 30's is paired anchor by anchor ($t=-5.3$, at a greedy $8.6$ tokens against a $10$-token filler); the run-25 and run-27 probes predate the per-anchor dump, so their bars are the conservative independent combination---$3.2$ and $2.4$ standard errors, at $9.4$ and $9.55$ tokens against the same $10$-token filler---and we do not quote a paired bar we cannot compute. The filler floor itself is displaced to $-1.61$ by the scheduled sampling of Section~\ref{sec:run30}. The last checkpoint of the programme repeats it with the gap at its widest: run 34 @800, the writer that speaks at every position, is $-0.81 \pm 0.08$ below length-matched filler on the same $465$ paired windows, and $-0.69 \pm 0.17$ on the $93$ of them where its own thought is exactly the filler's nine tokens long, so none of it is a length artefact. The ordering holds at every truncation length: at $m=2,4,6,8,12$ tokens run 28 scores own-minus-filler $-0.11, -0.30, -0.51, -0.70, -0.70$. Two other content sources we can generate are worse still: an in-context \emph{recall} span chosen for maximal content-word overlap with the window scores $-3.09$, and a random context span $-2.69$. Seven checkpoints---runs 25, 27, 28, 30, 31, 32 and 34---seven designs, five lengths, one conclusion: the written thought is below the empty slot.

\paragraph{N3. It is not the reward shape.} Raw counterfactual gain, shuffle-corrected gain, leave-one-out paired advantages over $R{=}8$ rollouts, and a baseline equal to the model's own greedy thought all produce the same picture. Nor is it the supervision fraction: a quarter, a tenth, and zero were tried; zero collapses into context-free register phrases within a thousand steps (Section~\ref{sec:phaseBres}), and a tenth is indistinguishable from a quarter on every instrument.

\subsection{What the slot's geometry costs}
\label{sec:slotpos}

One component of the first deficit is mechanical and was ours. A thought token $i$ was spliced at position $n{+}2{+}i$, one step further from the context than the real token $x_{n+1+i}$ it stands for. Scoring the identical buffer twice and changing only the position vector (\texttt{probe\_slotpos.py}, run 25 @900, $232$ anchors, true continuation in the slot): in-slot next-token accuracy $0.270 \to 0.305$ against a clean ceiling of $0.413$, and the reader's gain from identical content $+2.30 \to +3.15$ nats. Nothing about that is a capability limit; it is $0.85$ nats of register error that every run of this project has paid.

\section{Run-by-run evidence}
\label{sec:experiments}

\subsection{Setup}
\label{sec:setup}

\paragraph{Model and data.} A 0.6B-parameter transformer (Qwen3-0.6B architecture: 28 layers, hidden size 1024, GQA, vocabulary 151{,}936, untied head) trained \emph{from scratch} with sequence length 1024 on a 74/16/10 mixture of FineWeb-Edu, FineMath and DCLM. The pilots and the programme run on one AWS trn2.48xlarge node (16 Trainium2 devices, 64 NeuronCores, 1.5\,TB of accelerator memory); every result before run 15 was produced on a 4-core trn2 node. The programme uses all 64 cores as data-parallel ranks with two micro-batches each, i.e.\ $131{,}072$ tokens per step---the same global batch as every run since run 15---at ${\sim}27$\,s per step, of which the sequential decode of $L$ thought tokens is the larger part. Summing each run's own token counter, runs 15--34 account for $4.99$B thinking-mode tokens ($3.82$B of them in runs 20--34, the fp32 lineage that carries every result in this paper); runs 1--14, on the 4-core node at a $32{,}768$-token step, add a few hundred million more. The abstract's ``roughly $5$B'' is that sum.

\paragraph{The ladder.} The vanilla run was trained for $3.01$B tokens on the original mixture and then continued for $8.97$B fresh tokens of a disjointly drawn 9B-token corpus, saving a rung every $49.8$M tokens up to $11.98$B (80 rungs are kept); its held-out mixture cross-entropy is $2.775$ at $8.99$B. Phase A starts from the rung at $8.04$B total tokens. The sampler draws random windows, so that rung has seen ${\sim}43\%$ of the fresh corpus once, and $3.5$B further tokens is mild repetition rather than epochs; the vanilla rung at ${\sim}11.5$B is the equal-token control for the whole programme.

\paragraph{Parameter precision.}
\label{sec:precision}
Every run through run 18 kept its \emph{parameters} in bf16 and, from run 15, updated them with plain AdamW and no fp32 master copy. Round-to-nearest drops any update smaller than half the spacing between representable values, and bf16 has seven mantissa bits, so at a learning rate of $5\times10^{-5}$ every weight with $|w| \ge 2^{-6} \approx 0.016$ never moves at all: measured on the initial checkpoint, that is $52\%$ of the query projections, $42\%$ of the MLP down-projections, $64\%$ of the output head, and every normalisation gain (magnitude ${\sim}1$, spacing $2^{-8}$), while weights in $[2^{-7}, 2^{-6})$ move by a full step of $6\times10^{-5}$ whenever they move. Runs 15--18 therefore trained the \emph{small half} of every matrix, at a rate that was never really the nominal one, and the frozen half quietly protected the base model from the three new loss terms. We first noticed the normalisation weights ($113/113$ bit-identical to initialisation after thousands of steps) and diagnosed too narrowly. The vanilla ladder itself is unaffected: it trained with ZeRO-1, whose fp32 accumulators act as master copies.

Keeping parameters in fp32 with bf16 compute under autocast is the fix, and it is what mixed precision means; run 19 was the first run with it (resumed from a run-18 checkpoint), run 20 the first from scratch. Run 20 then exposed the consequence: with every weight moving at the nominal rate, learning rate $5\times10^{-5}$ overwrites the base (Section~\ref{sec:run20}). Every learning-rate choice made under bf16 is void, and the held-out cross-entropy of every checkpoint is now scored on a fixed 32-sequence ruler as part of the run itself, because the training loss is measured on a deterministic batch stream whose difficulty varies with the step and cannot be read as base health.

\subsection{Evaluation protocol}
\label{sec:evalproto}

Training-time observables, all logged every step: clean NTP on real tokens; the leak-free oracle gain $\mathrm{orG}$ (the reader's response to the true continuation at supervised anchors); imitation cross-entropy; the mean sampled gain $\gain$; the eligible rate (fraction of reinforcement thoughts with $\gain > 0$, i.e.\ that beat silence); and the winner's shuffle $\gain_{\mathrm{shuf}}$. Beyond these we compare thinking checkpoints against vanilla rungs on a zero-shot likelihood suite (LAMBADA, HellaSwag, WinoGrande, ARC-Easy, ARC-Challenge, OpenBookQA, SciQ, BoolQ; 500 examples each; length-normalised accuracy) in two modes: \emph{clean}, with no thoughts, measuring whether thinking training changed the base; and \emph{think}, with a $64$-token thought generated at one anchor before the continuation, spliced exactly as in training---the overlapping integer positions and the mask that hides the anchor token from the window row that re-emits it. A plain concatenation is a geometry the model has never seen and scores LAMBADA at $0\%$; reproducing the training splice is not optional. The splice must also use the \emph{register} the checkpoint was trained in: runs up to 29 place thought token $i$ at position $n{+}2{+}i$ (\emph{built}), runs 30 onward at $n{+}1{+}i$ (\emph{aligned}). Scoring an aligned checkpoint in the built register moves individual gold log-probabilities by up to $1.4$ nats, so every think-mode row records the register it was scored in. Per-example outputs are paired across checkpoints (McNemar on accuracy, paired $t$ on gold log-probability).

\subsection{Pilot I (run 18): compulsory thinking at $L{=}16$}
\label{sec:run18}

Run 18 is the first run of the procedure of Section~\ref{sec:procedure}---mixed anchors, no gate, $L_{\min}{=}8$, $L{=}16$, $R{=}8$, raw-gain reward, shuffle as instrument---from the $8.99$B rung, for $2{,}200$ steps ($288$M thinking-mode tokens), with bf16 parameters (Section~\ref{sec:precision}). It is the phase-A configuration minus the precision fix.

The mechanical claims hold throughout. The realised think-rate is $1.00$ at every step---with no gate there is nothing to close, and the evasion that ended every earlier reinforcement run is unavailable. Thought lengths settle at $10.6$ tokens of the $16$ available rather than at the $8$-token floor, so trivially short thoughts are not the escape either. The supervised channel behaves: imitation CE falls $5.04 \to 3.79$ and the leak-free oracle gain climbs $-11.7 \to -1.8$.

The fraction of forced thoughts with \emph{positive} raw gain---thoughts that beat silence outright---rises from $1\%$ to $45\%$, an order of magnitude above anything the earlier designs reached under any configuration.

The two order columns must be read with the caveat of Section~\ref{sec:rollouts}, and an earlier draft of this paper did not: it reported the first of them ($-1.7$ nats, mean rollout against the winner's shuffle) as the winner's cost against its own shuffle, and built a story about ``confident wrong commitments'' on it. Compared like with like, the winner beats its own shuffle by $+0.8$ nats at the end of the run, positively on $82\%$ of anchors. That is the ``make thoughts harmless'' dynamic of Appendix~\ref{sec:run17} in a new form, now visible on a model that cannot decline to think. Compulsory thinking has converted a model that ignored its thoughts into one that responds to them; whether the response is to their content or to their register is what the non-selected shuffle will decide.

The thoughts themselves are short topical continuations. Two reinforcement-anchor winners from the dumps (every record carries its provenance; none of these is a supervised anchor):

\end{quote}
Among the $29{,}852$ reinforcement winners that beat silence, $82\%$ have positive order-borne value (mean $+1.06$ nats, median $+0.91$). We note what the largest margins are made of: they are carried by shuffles that are catastrophic ($-10$ to $-16$ nats) rather than by thoughts that are good ($+0.9$ to $+3.5$)---a reader that has learned to follow structure is badly hurt when that structure is destroyed, which is the same sensitivity read from the other side.

One plateau deserves comment, because it looks like a failure and is not. Imitation CE settles at $3.8$--$4.2$ in \emph{every} run we have logged, almost independently of configuration: run 15, whose supervised target sits $9$--$20$ tokens beyond the anchor, plateaus at $3.84$; run 18, whose target sits $65$--$80$ tokens beyond it, plateaus at $3.80$. A seven-fold change in how far ahead the model must see moves the achievable cross-entropy by under $0.05$ nats. The supervised channel is not failing to learn---it is sitting near the entropy floor of its task. Predicting a \emph{specific} 16-token span that has not yet been written is mostly unknowable; what remains knowable is topic, register and the shape of the construction, and that is what the model learns to emit. This matters because it is the same content the reinforcement channel is then measured on: a teacher that can only convey topical plausibility produces thoughts whose value is topical, which is exactly the priming $\gain_{\mathrm{shuf}}$ detects. The two halves of the design are consistent with one another, and both point at the same ceiling.

Clean NTP drifted $+0.09$ nats over the run, the ordinary multi-task cost of a thinking head that earns little, and far inside the $+0.5$ guard.

Making the writer speak is downstream-neutral; it is only the held-out value of what it says that is negative.

\emph{Think mode at inference loses to the same weights in clean mode, as the held-out probe predicted.} We registered the prediction \emph{think $\le$ clean} before the arm was scored, on the grounds that the same checkpoint's own thought is worth $-0.81 \pm 0.08$ nats against length-matched filler on held-out text (Section~\ref{sec:run34}). It holds: macro $-1.4$, pooled over all $4{,}000$ examples $-1.43$ points (McNemar $p = 4 \times 10^{-4}$), LAMBADA $-6.0$ ($p < 10^{-3}$), and no task gains by more than noise; the five-task pool alone is $-0.52$ ($p = 0.35$). Thinking at inference costs about one and a half points of accuracy and buys nothing, on the one checkpoint of the programme that actually writes words into the slot.

\emph{And it writes almost the same words every time.} The greedy thoughts this arm produced are $258$ distinct strings over $4{,}000$ examples; a single one---\texttt{The first step in the process is to determine the type of}---is emitted at $1{,}083$ of them, and on BoolQ the $500$ questions receive $22$ distinct thoughts between them. LAMBADA, where the context is ordinary prose rather than a question stem, is the most varied at $137$. This is the order-borne-value result of Section~\ref{sec:run25} arriving from a completely different direction and on a different corpus: what the writer has learned to emit is a \emph{register}, nearly independent of what it was asked to think about, and the benchmark cost is what that register displaces.

\paragraph{What every checkpoint has in common.} The model knows facts and reads (SciQ $72$--$74\%$, LAMBADA $33$--$35\%$ for vanilla) and \emph{cannot reason}: WinoGrande and ARC-Challenge sit at chance for every checkpoint, thinking or not, which bounds what any thought can currently be about.

\subsection{Phase A, first attempt (run 20): the learning rate that was never tested}
\label{sec:run20}

Run 20 launched phase A on 2026-09-10: 64 ranks, fp32 parameters, from the $8.04$B rung, at the learning rate every previous run had used ($5\times10^{-5}$, cosine to $3\times10^{-5}$). The thinking observables behaved as in run 18---eligible rate $1\% \to 47\%$ by step $2{,}300$, imitation CE $4.6 \to 4.2$, oracle gain $-11 \to -1.2$, winner over own shuffle $+0.8$---and the base model was being destroyed underneath them. On the held-out ruler the mixture cross-entropy went $2.786$ (init) $\to 3.040$ (step $500$) $\to 3.157$ ($1{,}000$) $\to 3.246$ ($1{,}500$) $\to 3.317$ ($2{,}000$) $\to 3.351$ ($2{,}300$): $+0.56$ nats, monotone, a quarter of it in the first $500$ steps, against run 15's total tax of $+0.13$ after $2{,}500$ steps. Paired on identical batches (the sampler is seeded by step, so runs 15 and 20 saw the same rows and their training losses correlate at $0.97$), run 20 sat $+0.11$ nats above run 15 in the first $300$ steps and $+0.42$ by step $2{,}300$; the reinforcement weight was still zero when the gap opened, so reinforcement is not the cause. The weights moved twice as far as run 18's at the same step (query projections $8.3\%$ vs $4.3\%$ relative change, output head $35\%$ vs $20\%$), and the normalisation gains moved $0.3\%$---they are not the cause either. It is the projections, finally all trainable, being pulled toward three new losses at a rate the base was never trained at (the vanilla ladder ran at a constant $3\times10^{-5}$). We killed the run at step $2{,}307$.

Run 21 restarted phase A on 2026-09-11 with the same configuration at learning rate $10^{-5}$ (cosine to $5\times10^{-6}$, $200$-step warmup), with the held-out probe in the loop. At step $3{,}600$ (47\%) the held-out mixture CE is $2.886$, $+0.10$ over the init rung, against run 20's $+0.46$ at the same step and run 15's $+0.13$ at step $2{,}500$; the slope has flattened to ${\sim}0.002$ nats per hundred steps. Every thinking observable sits where run 18's did at its end---eligible rate $0.46$, length $10.6$, imitation CE $3.82$, oracle gain $-1.8$, winner over own shuffle $+0.84 \pm 0.02$---reached in $1.6\times$ the steps rather than the $5\times$ a naive learning-rate scaling would predict. The thinking channel is invariant to the learning rate and to the precision fix; only the base tax changed.

\subsection{Phase B (runs 22--23): the supervised anchor is load-bearing}
\label{sec:phaseBres}

Run 22 ran phase B as first specified---$\rho = 0$, every anchor a reinforcement anchor, from run 21's final checkpoint at learning rate $10^{-5}$---and reproduced the handover failure of Appendix~\ref{sec:run13obs} in a new form within $1{,}400$ steps. The rewarded quantities all improved (eligible rate $0.50 \to 0.63$, winner over silence $-0.02 \to +0.25$, held-out CE only $+0.044$), while the thoughts hollowed out underneath them: the spread of the eight rollouts' gains per anchor halved ($1.7 \to 0.9$; the samples were converging), lengths dropped to the $8$-token floor, and \emph{context-free register phrases} began to win---\texttt{0 at least one of the above statements is} after a polynomial question, \texttt{0 at least one of the works of} in a bibliography, \texttt{0 at least three hours} after an aviation paragraph---rising from $0\%$ of winners at step $200$ to $10\%$ by step $1{,}000$, receding, and being replaced by \texttt{in this}, then \texttt{and time}, with the top three such prefixes reaching $20\%$ of winners by step $1{,}400$. These thoughts have small positive gain and positive \emph{shuffled} gain: the raw-gain reward pays for register, and with no supervised anchor nothing in the loss opposes it. The run was stopped at step $1{,}435$.

Run 23 repeats phase B with $\rho = 0.10$: one anchor in ten keeps the true continuation. That is sufficient. At $1{,}900$ steps the register share is flat at $1\%$, rollout spread $1.7$, lengths $10.0$, eligible rate $0.55$, winner over own shuffle $+0.79$, held-out CE $+0.064$ and slowing---every quantity where phase A left it. It is also \emph{only} that: nothing has improved over the last $1{,}000$ steps. Lowering supervision from a quarter of anchors to a tenth neither broke the writer nor freed it. The reinforcement channel, given a policy worth exploring from and $900$ steps at full weight, adds nothing that the instruments can see, and removing the supervised channel entirely converts it into a register generator within a few hundred steps. It ran its full $3{,}800$ steps ($0.5$B tokens) and the picture did not change: final block eligible $0.57$, winner over own shuffle $+0.80$, register $0.9\%$, held-out CE $3.036$ ($+0.095$).

\subsection{Run 24: the sketch target}
\label{sec:run24}

Run 24 continues from run 21's final checkpoint with one change: the supervised thought is a $16$-token span from \emph{inside} the scored window at a random offset $8 \le o \le 48$ (the lower bound excludes plain speculative decoding of the next tokens). It also logs, for the first time, the unbiased order-borne value $\mathrm{ob}_0$: the gain of an \emph{unselected} rollout minus the gain of its own shuffle (Section~\ref{sec:rollouts}). The reader responded exactly as the probe predicted: oracle gain at supervised anchors went from $-1.4$ to $+4.6$ at step $0$ and $+7.4$ by step $3{,}800$. The writer did not: over $3{,}800$ steps imitation CE stayed at $3.7$, and an unselected sampled thought stayed worth $-2.5 \to -2.2$ nats against silence, with $\mathrm{ob}_0 = -0.2$ throughout. Held-out CE $2.941 \to 3.027$. Nothing was bought.

The run exposes the actual defect. The reader was optimal for the mixture it was trained on: a quarter of hints were the true future (worth $+7$), and every self-written hint in the buffer was the \emph{best} of eight. Trusting hints pays on that mixture; at inference, where the only hint is one unselected thought of the model's own, the same trust costs $2.2$ nats. The writer, rewarded by a reader that trusts everything, is never told that confident wrong content hurts.

\subsection{Run 25: calibrating the reader to inference}
\label{sec:run25}

Run 25 (from run 24's final checkpoint) trains the reader only on what it will meet at inference: the reader loss is removed at supervised anchors (the writer still imitates the sketch there), and reinforcement anchors splice a \emph{random} rollout rather than the winner, so REINFORCE acts on an unselected sample with its leave-one-out advantage (mean zero, unbiased) instead of on the winner alone. The reinforcement weight rises from $0.15$ to $0.5$ (negatives damped $2\times$ instead of $4\times$), and the greedy row---what a user of the model would get from thinking---is now scored every step. The decisive quantities are the gains of the unselected sampled thought and of the greedy thought: at step $0$, $-2.2$ and $-1.4$ nats. Thinking has bought something when either is positive on held-out text, measured with the model generating its own thoughts (\texttt{probe\_thinkmode.py}); a reader that merely learns to ignore thoughts will bring them to zero and no further.

This is the largest held-out movement the programme has produced, and it is not the movement we were looking for. Two explanations remain, and they are not distinguishable from anything measured so far: the gain is the reader's recalibration together with the extra positions the thought occupies, or it is content too weak for the shuffle monitor to detect. \paragraph{The verdict, and it is against us.} Run 25's halving of the cost of thinking was extra computation plus a recalibrated reader. A written thought is worse than leaving the slot blank. The pre-registered consequence, written before run 26 was launched, was that if filler earned what the written thoughts earned we would report having bought compute rather than thinking; filler earned more, and that is what we report.

\paragraph{The reader is order-blind, not content-blind.} The last row of Table~\ref{tab:run26probe} corrects the natural misreading of run 25. One might conclude from $\mathrm{ob}_0 \approx 0$ that the reader has learned to ignore the thought slot. It has not: feeding run 26's filler-trained reader a real written thought is catastrophic, far worse than any condition in this paper. So the reader conditions very strongly on \emph{what kind of thing} occupies the slot. We originally read this together with $\mathrm{ob}_0 \approx 0$ as indifference to the \emph{order} of the tokens within the slot; Section~\ref{sec:probes2609} shows that inference was wrong---shuffling a \emph{real} hint destroys $10.5$ of its $10.7$ nats---and that $\mathrm{ob}_0 \approx 0$ is a statement about our writers, not about the reader. Any mechanism that hopes to make thinking pay has to create order-borne value that this reader can see, and no configuration we have run creates any.

\paragraph{Everything on one scale.} Collecting the measurements that share the units of nats over silence on the same $64$-token window: a perfect $12$-token hint from inside the window (the span $16$ to $28$ tokens after the anchor) is worth $+11.0$; content-free filler is worth approximately $0$; the model's own written thought $-1.2$; the $12$-token span of context with the highest content-word overlap with the window---a retrieval oracle, and a learnable one, since it is already in context---is worth $-3.1$, which is \emph{worse} than a random context span at $-2.7$. The reader has an enormous appetite for genuine information about the future and every content source we can actually produce at inference time is worse than silence. That, and not the reader's calibration or the shape of the reward, is what the programme is up against. It also retires a hypothesis before it cost a run: recall thoughts were queued on the condition that the reader value them at $+2$ nats or better, and they miss by five.

\subsection{Run 27, and three probes that locate the failure in the training target}
\label{sec:probes2609}

Run 27 changed exactly one flag from run 25---the REINFORCE baseline, from leave-one-out to the model's own greedy thought, so that a sample is reinforced only when it beats what the model would actually emit. It was stopped at step $826$ by the futility rule written into its configuration before launch. Over block $500$--$799$, $\mathrm{ob}_0 = -0.097 \pm 0.017$ against a required $+0.05$, and $g_{r0}$ gained $+0.278$ against a required $+0.30$. More telling than the rule is the decomposition: of that $+0.278$, $+0.224$ is shared with the gain of the thought's \emph{own shuffle}. The curve rose and nothing order-borne moved, exactly the failure mode the configuration predicted in writing. The baseline is not the bottleneck. The held-out filler bar of Section~\ref{sec:run26} replicates on this second, independently trained checkpoint: on run 27's own step-$800$ weights its written thought scores $-0.857 \pm 0.112$ against content-free filler's $-0.503 \pm 0.096$ at matched length ($9.55$ against $10$ tokens), a deficit of $-0.355 \pm 0.148$. Two runs, two reward shapes, the same verdict: the thought is worse than leaving the slot blank.

\paragraph{The first correction: the reader is not order-blind.} Section~\ref{sec:run26} inferred from $\mathrm{ob}_0 \approx 0$ that the reader reads a thought as a bag of words. We were measuring the writer and attributing the result to the reader.

\paragraph{The second: self-forecast writers are closed, by their own upper bound.} The one inference-available content source never tested is the model's own forecast of the window. \subsection{Run 28, the abstention ladder, and an arithmetic error in our own target}
\label{sec:run28}

Run 28 aimed the writer at offset $0$--$4$ and priced length, and was stopped at step $860$ by its own single-clause rule: $\mathrm{ob}_0 = -0.127 \pm 0.016$ over block $500$--$799$ against a required $+0.05$, eleven standard errors short and flat since step zero ($-0.185$, $-0.160$, $-0.127$ over successive $300$-step blocks). As in runs 25 and 27, $g_{r0}$ rose---$+0.369$---and $+0.311$ of that rise was shared with the thought's own shuffle.

It nevertheless produced the first movement the writer has ever shown. On the step-$200$ checkpoint the free-running thought's token agreement with the true continuation is $0.113$ at $m{=}2$, against $0.042$ for run 25 (Table~\ref{tab:draft}) and a unigram base rate of about $0.04$. Aiming at the near horizon changed what the writer emits.

\emph{And the model got worse by exactly the amount Table~\ref{tab:ladder} predicts.} own $-$ filler is more negative at every length than run 25's: $-0.24$ against $-0.05$ at $m{=}2$, $-0.79$ against $-0.32$ at $m{=}12$. This is the confident-wrong-token penalty running in the open. At eleven per cent the writer is far below break-even, so its tokens are wrong most of the time---but they are now \emph{plausible near-horizon} wrong tokens rather than visible noise, and the reader believes them. Run 25's babble was harmless; run 28's near-miss is harmful. Partial correctness is the worst place to be.

\paragraph{Abstention is readable, and it halves the bar.} If confident wrong tokens are the poison and filler costs nothing, the writer should be allowed to say nothing at positions it cannot forecast. Interleaved abstention is not merely tolerated, it is the better format.

\paragraph{The model's confidence is a good selector, and it is uniformly a few points short.} Second, does the model know \emph{where} it is right? It does, decisively: its two most confident positions are correct $81.3\%$ of the time and its top four $71.3\%$, against $44.2\%$ unselected. That is the precondition we registered before running the probe, and it passes. Yet every $\mathrm{selfconf}_C$ still scores below the filler floor, because the minority of confident-\emph{wrong} tokens costs more than the majority of right ones pays. Reading the two columns together gives the sharpest statement of the bar the project has: at every width, the model's own precision falls short of the break-even precision by between $0.03$ and $0.16$, and the shortfall shrinks monotonically as the writer is allowed to speak more. We are not an order of magnitude from a useful thought; at twelve tokens we are under three points of precision from one. But we have never been on the right side, and $\mathrm{self}_{16}$ is \emph{teacher-forced}---an upper bound no free-running writer has come close to. The free-running writer agrees on $11\%$ of tokens where the teacher-forced one is right $44\%$. Closing that gap, not changing the reward or the reader, is what the remaining budget should buy.

\paragraph{The cause of run 28's ceiling is arithmetic in our own configuration.} \verb|--oracle-mode jitter --oracle-min-off 0 --oracle-max-off 4| draws a fresh offset $o \sim \mathcal{U}\{0,\dots,4\}$ per anchor and supervises the writer on $x_{n+1+o}\dots$, while the reward always scores the window starting at $x_{n+1}$. The writer cannot observe $o$. A writer that bets optimally on offset $0$ is therefore right at most $0.44 \times 0.2 = 0.088$ of the time on the token that is actually scored; run 28 measured $0.113$. The training log carries the same signature independently: run 28's imitation cross-entropy plateaued within a hundred steps at $3.48$ against its own clean next-token entropy of $2.78$, an excess of $0.70$ nats that never came down---an irreducible-ambiguity floor, not a learning curve. Four runs excluded the immediate continuation as a trivial copy and the fifth, which finally aimed at it, hid it behind a five-way lottery. Run 29 changes that one value to \verb|--oracle-mode fixed --oracle-off 0| and nothing else, with a falsification check at step $300$: if the imitation cross-entropy does not fall to within $0.3$ nats of the clean next-token entropy, this diagnosis is wrong and the run stops there. A third trace, measured after the run was stopped: re-probing run 28's \emph{step-$800$} checkpoint on the same $n=465$ anchors gives agreement $0.116$ at $m{=}2$, against $0.113$ at step $200$. Six hundred further steps of training moved the writer's agreement by three thousandths. The ceiling was not approached during run 28---it was reached inside two hundred steps and then held, which is what a floor imposed by unobservable ambiguity looks like and is not what a capability limit looks like. (Its own $-$ filler gap at step $800$ is $-0.11$ at $m{=}2$ and $-0.70$ at $m{=}12$, still below the floor at every length.)

\subsection{The writer can forecast; free running destroys it}
\label{sec:tfslot}

Every result above measures a \emph{free-running} thought and finds it worthless. The abstention
ladder measures a \emph{teacher-forced} one and finds it just short of useful. Those two regimes had
never been compared on the same rows, so the gap between $11\%$ and $44\%$ had no attribution. Two
mechanical explanations can be dismissed immediately by reading the sampler: both code paths
special-case the speculation row with a bare \texttt{argmax}, so the greedy thought receives no
top-$k$ truncation, no frequency penalty, no repeat ban and no temperature---every ``own greedy''
number in this paper is a plain argmax---and the repeat penalty the \emph{sampled} rollouts do carry
would block only $0.46\%$ of true continuation tokens ($n=232$ spans). Decoding is not the cause.

Table~\ref{tab:tfslot} separates the two remaining ones. On a single checkpoint (run 25 @900), a
single set of $n=616$ anchors and a single forward pass, it reports positional agreement with the
true continuation under three conditions: \textsc{ntp}, the clean row $n{+}i$ predicting $x_{n+1+i}$;

check: at position $0$ the thought prefix is empty, so \textsc{tfslot} and \textsc{own} are
necessarily the same row---and they agree to the digit ($0.047$).

regime, in two compounding parts. Position $0$ fails on its own: the $\langle T\rangle$ row attends
to exactly the context the clean row $n$ attends to, and scores $0.047$ against $0.433$---a ninefold

The cause is once again in what we train, not in what the model can do. \verb|--imit-w 1.0|
supervises the writer with the thought block holding the true continuation---pure teacher
forcing---so every run in this paper has trained the regime that works and never the regime it
samples in. The implied next experiment is scheduled sampling: build the imitation block from the
model's own sampled prefix while keeping the true continuation as the target, ramping the
own-prefix probability through the run. We pre-register its bar here: \textsc{own} agreement over
positions $1$--$11$ must reach $0.15$, against the $0.019$ of Table~\ref{tab:tfslot}. The one caveat
is that \textsc{tfslot} decays past position seven and collapses at $14$--$15$ ($0.09$, $0.01$),
beyond run 25's trained thought length of about ten tokens; that tail is out of distribution rather
than a limit on forecasting.

artefact of that target. Run 29 supervises the immediate continuation and position $0$ rises to
$0.297$ against the clean row's $0.427$---a factor of $1.4$, not $9$. Three further things follow,
and the third is the one that matters. Free-running agreement over positions $1$--$11$ improves by
$3.4\times$ ($0.0193 \to 0.0657$), the largest such move we have measured, and \emph{the base model

teacher-forced ceiling does not move ($0.347 \to 0.366$), so what run 29 bought is free-running
fidelity rather than new capability---exactly what the exposure-bias account predicts a

same table shows is the worse of the two. What has changed qualitatively is the shape of the
failure: \textsc{own} now decays smoothly ($0.297$, $0.185$, $0.123$, $0.102$, $0.071$, \ldots)
instead of collapsing at position $1$, and the teacher-forced-to-free ratio falls from $18.0\times$
to $5.6\times$. That decay curve is the exposure-bias signature, and flattening it is what the next
run is for.

\subsection{Run 30: scheduled sampling is falsified, and it costs the ceiling it was meant to unlock}
\label{sec:run30}

Table~\ref{tab:tfslot29} says the capability is present teacher-forced and that only the decoding
regime destroys it. The standard remedy for exactly that is scheduled sampling: train on the model's
own prefix rather than on the true one. Run 30 is that experiment, and it adds one further change
whose justification was measured separately---\verb|--slot-pos aligned|, which puts thought token $i$
at the position of the real token $x_{n+1+i}$ it stands for, instead of one step further out. Both
were applied from the same run 25 @$1500$ initialisation as runs 27--29, so the comparison to run 29
at matched steps is exact. A single bar was registered before the run, against a control computed
from run 29 at the same step $600$ and deliberately not read until the bar was due: free-running

\paragraph{It failed, and it failed below its own control.} Run 30 reached $0.0689$ against a bar of
$0.15$ and against a no-scheduled-sampling control of $0.0751$, and its trajectory over the interval
in which the substitution probability actually ramped ($0.25 \to 0.63$ between steps $300$ and $600$)
was flat to falling: $0.0704 \to 0.0689$. Because the two interventions can be separated by reading
the same checkpoint in both registers, we can attribute this. The position change is worth
$+0.0096$ on the deciding column---about the size of run 29's entire gain from step $500$ to step
$600$---and it survives the run. Scheduled sampling, isolated by comparing like register with like,
contributes $+0.0003$ at step $300$, where its probability is still low, and $-0.0134$ at step $600$.
The sign flips as the ramp climbs.

\paragraph{What makes this a falsification rather than a null: the teacher-forced ceiling collapsed.}
Between steps $300$ and $600$, $\textsc{tfslot}(1\text{--}11)$ fell $0.3850 \to 0.2741$ in the aligned
register and $0.3682 \to 0.2395$ in the built one, against run 29's much gentler $0.3918 \to 0.3346$
over the same steps. Run 30 destroyed roughly $0.11$ of precisely the capability it was built to make
usable, and bought nothing free-running in exchange. The mechanism is visible in the objective:
scheduled sampling feeds the model its own sampled prefix while keeping the \emph{true} continuation
as the cross-entropy target, and given a wrong prefix the true next token is frequently not a
function of what the model has just written. The irreducible part of that loss is noise, it is
applied to weights shared with the teacher-forced pathway, and that pathway is what degrades. This
is the same failure as run 28's offset lottery in a different costume---there the target was a
five-way mixture over an offset the writer could not observe---and the general rule we draw from the
pair is to ask, before building a training signal, whether a perfect model could achieve zero loss
on it. If it could not, the residue lands on shared weights.

\paragraph{What remains open, and the honest ceiling.} Exposure bias is not refuted as a
\emph{description}: Table~\ref{tab:tfslot29}'s gap between $0.35$ teacher-forced and $0.02$ free is
still the largest single deficit we can point at. What is refuted is reaching it by splicing own
inputs onto true targets. Two routes remained when this section was written, and both have since
closed. The first was simply more training: run 29's free-running agreement appeared to be rising
monotonically at $+0.0094$ per hundred steps when it was stopped at step $780$ by
an $\mathrm{ob}_0$ gate that the ladder of Table~\ref{tab:abst} has since shown cannot fire below two
or three correct tokens of twelve, so no run had ever been allowed to continue on that trajectory.
Run 31 was that run---run 30 with scheduled sampling switched off and nothing else changed, registered
against trajectory gates at steps $600$, $1000$ and $1500$---and it retires the slope: at matched
register and matched anchor count its own agreement reads $0.0716$ at step $300$ and $0.0722$ at step
$600$, so run 29's apparent rate was a climb to a level, not a rate of learning
(Section~\ref{sec:run31}). The second was to remove
self-conditioning structurally rather than to train around it---a non-autoregressive slot, in which
row $i$ predicts $x_{n+1+i}$ from the context alone and error propagation is impossible---and because
that is cheap to measure before it is run, we measured it (next paragraph) and it does not survive
contact. We state the bound that limits both in advance: break-even against the
filler floor is about two correctly-positioned tokens of twelve with pause padding, and the
\emph{teacher-forced} ceiling is only about $4.1$ of twelve, so even a perfect fix to the
free-running gap is worth around $+0.6$ nats over filler, not the $+10.7$ of a true hint. Nothing on
this path can be a landslide, and we would rather say so here than discover it in a result.

\paragraph{The parallel slot is not the escape either (\texttt{probe\_tfslot.py -{}-nar}).} Filling
the thought block with content-free filler makes row $i$ of the block predict $x_{n+1+i}$ from the
context alone: the model's wrong prefix cannot propagate, because there is no prefix. On the two
checkpoints that bracket the question---run 29 @600, the healthiest free-running writer we have, read
in its own built register, and run 30 @600 in the aligned register run 31 trains in---the probe's
built-in alignment identity passes exactly ($\textsc{nar}@1 = \textsc{own}@1 = \textsc{tfslot}@1 =
0.305$, as it must at position $0$, where all three conditions are the same row), and over positions
$1$--$11$ it reads $\textsc{nar}\ 0.020$ against $\textsc{own}\ 0.071$ and $\textsc{tfslot}\ 0.330$
for run 29, and $0.018$ against $0.069$ and $0.274$ for run 30. The parallel slot is not merely below
the teacher-forced ceiling, it is three to four times worse than free-running autoregression: the
model's own \emph{wrong} prefix is worth more to it than no prefix at all. We record the asymmetry in
what this licenses, because we drafted it the other way first. Had $\textsc{nar}$ come out near
$\textsc{tfslot}$ it would have been strong evidence, in the way $\textsc{tfslot} \gg \textsc{own}$
was: capability sitting unused. $\textsc{nar} \ll \textsc{own}$ is weak, because no run has ever
trained the parallel regime while $\texttt{-{}-imit-w 1.0}$ trains the teacher-forced one directly.
The honest reading is a lower bound---there is no free lunch here, and a non-autoregressive slot is
not a probe away from working---not that parallel decoding is dead.

\subsection{Run 31: the trajectory was not a trajectory}
\label{sec:run31}

Run 31 was run 30 with scheduled sampling switched off---one flag, \texttt{-{}-dagger-p 0.0}, which is
argparse's own default and which both call sites gate on, so the run is exactly run 29 plus the
aligned register, allowed to continue where run 29 was stopped. Its purpose was narrow and, we
thought, unglamorous: run 29's free-running agreement had risen monotonically, $0.0605$ at step $300$
to $0.0657$ at $500$ to $0.0751$ at $600$, and had never been allowed to continue. Run 31 gave that
trajectory $2{,}000$ steps and three gates on it.

It failed the first gate, and the manner of the failure is more informative than the fact. At step
$600$, in the aligned register it was trained in and at the $n=616$ anchors every bar in this paper is
calibrated on, $\textsc{own}(1\text{--}11) = 0.0722$ against a gate of $0.0751$---a shortfall well
inside one standard error, and we do not claim run 31 is worse than run 29. What decides the run is
the other reading, which needs no comparison to another run at all: \textbf{measured at matched
register and matched $n$, run 31's own trajectory is flat.} It reads $0.0716$ at step $300$ and
$0.0722$ at step $600$: three hundred steps of training, at $131{,}072$ tokens each, moved the
free-running writer by $0.0006$. The aligned register delivers its entire contribution by step $300$
and then nothing further happens. Run 29's apparent slope of $+0.0094$ per hundred steps was a
different checkpoint climbing to the same level from a lower start, not a rate of learning that more
compute would extend.

That makes run 31 the fourth independent measurement of the same thing, and the four differ in what
they vary. Run 28 hit its agreement ceiling within $200$ steps and held it for $600$ more
($0.113 \to 0.116$). Run 30 varied the decoding regime with scheduled sampling and finished
\emph{below} its control. The non-autoregressive probe varied decoding order and came out three to
four times worse. Run 31 varied training length and moved nothing. Exposure bias, decoding order and
optimization time have each now been given a run or a probe of their own, and the free-running writer
sits at the same place after every one of them. We stop treating it as a quantity that will improve
and start treating it as a floor.

No derail axis fired: held-out mixture cross-entropy rose $3.1115 \to 3.1298$ over $800$ steps, $7\%$
of its $+0.25$ allowance, the register share stayed at $1.0\%$, and there were no NaNs. Run 31 is a
clean falsification of its own hypothesis rather than a run that broke.

\paragraph{An instrument bug worth recording, because we nearly held a run to it.} Run 31's gates were
quoted from files probed at $n=616$ anchors while the waiting scripts were probing at $n=465$. Because
the probe consumes the first $\textsc{nper}$ sequences per domain, the $465$ are a nested subset of the
$616$---the same anchors, fewer of them, and a different mean. On run 29's own step-$600$ checkpoint in
its own register, $\textsc{own}(1\text{--}11)$ reads $0.0751$ at $n=616$ and $0.0714$ at $n=465$, so
holding run 31 to $0.0751$ while measuring it over $465$ anchors demanded strictly more than the gate's
own stated meaning. We raised the measurement rather than lowering the bar, which leaves the
pre-registration standing verbatim; editing a gate after seeing data is the failure mode this paper's
gates exist to prevent. A bar quoted from an older file inherits that file's anchor count, its
positional register and its flags, and all three have to be re-read before a run is held to it.

\paragraph{The accuracy--harm relation reverses between checkpoints and within one.} Run 31 @800 is the
most accurate free-running writer we have trained and its thought is the most harmful. Paired over the
same $n=465$ held-out anchors, the thought loses to a length-matched blank slot by
$-0.325 \pm 0.065$ nats at $m=2$ ($t=-4.96$) and by $-0.834 \pm 0.096$ at $m=8$ ($t=-8.71$); this is the
fourth checkpoint, after runs 25, 27 and 28, at which a written thought is worse than saying nothing.
Across checkpoints the harm grows \emph{monotonically with the accuracy}: at $m=2$, agreement
$0.042 \to 0.116 \to 0.260$ for runs 25 @900, 28 @800 and 31 @800 against own-minus-filler
$-0.05 \to -0.111 \to -0.325$. Within run 31 @800, however, the per-anchor correlation has the opposite
sign: $r(\text{agreement}, \text{own}-\text{filler}) = +0.180$ at $m=2$ ($t=+3.94$, $n=465$), and
splitting by agreement quartile, the anchors where the writer is most right cost nothing at all
($-0.082 \pm 0.105$, indistinguishable from zero) while the anchors where it is never right cost
$-0.470 \pm 0.083$. The two signs reconcile if accuracy gains arrive bundled with a larger plausibility
cost on the $74$--$90\%$ of anchors still wrong---a better writer is confidently wrong in more
believable ways, which is the self-forecast mechanism of Section~\ref{sec:probes2609} again. This is the
first positive evidence in the project for \emph{selective} speaking, and we state its ceiling with the
same care: perfect anchor-level gating on this checkpoint reaches break-even, not a positive number, and
$r=+0.18$ is weak enough that a realistic selector captures only a fraction of it. It is a direction
with headroom, not a result.

\subsection{Run 32: paying for silence instead of for wrong guesses}
\label{sec:run32}

Every design so far has tried to make the writer right more often. Four measurements say that is the
quantity that does not move. Run 32, since stopped at step $1130$, attacked the other term instead---the
one that is larger and that we have measured repeatedly without acting on it. A confident wrong token
is more expensive than a blank slot: the teacher-forced self-forecast is right $5.30$ of twelve and
scores $1.2$ nats \emph{below} the mixture-ladder rung at its own accuracy, and run 28 raised
near-horizon agreement from $0.042$ to $0.113$ while its deficit against filler got worse at every
length. The writer currently emits about twelve confident tokens, of which roughly $10.9$ are wrong,
and it pays for all of them.

The format that lets it stop paying is already measured as readable. In the abstention ladder of
Section~\ref{sec:probes2609}, true tokens in their true positions with content-free filler
\emph{interleaved} between them beat the same count of true tokens padded with context noise at every
width---$-0.71$, $-0.16$ and $+0.77$ at two, four and six correct tokens against a filler floor of
$-0.74$---which drops break-even from roughly four correct tokens of twelve to two. Run 32 therefore
supervises the writer on that format directly: in the imitation block the true token is kept only
where that token is one of the $300$ most frequent unigrams, and every other position is filled with
content-free filler. On the validation mixture those tokens are $55\%$ of the next twelve, so the
supervised thought carries about $6.6$ content positions and $5.4$ silences.

Two properties of this mask are the reason for choosing it over a learned confidence head. It is
model-free, so it costs no additional forward pass; and because the block input and the
cross-entropy target are both built from the same array, the mask applies \emph{identically} to what
the model conditions on and what it is asked to produce. That train/inference regime-match is exactly
what run 30 spent an extra generate pass trying to buy, and lost $0.013$ of free-running agreement
doing. The arithmetic of the bar is unchanged and absolute: expected correctly-positioned tokens is
$\textsc{own}@0 + 11\,\textsc{own}(1\text{--}11)$, run 31 sits at $1.11$ of twelve, break-even is
two, and with the opener held at ${\approx}0.31$ that requires $\textsc{own}(1\text{--}11) \ge 0.154$,
or a precision of $0.30$ on the $6.6$ positions the writer is allowed to speak at. The gates are
$\ge 0.0722$ at step $600$ (do no harm relative to run 31 at the same step), $\ge 0.105$ at $1000$
and $\ge 0.154$ at $1500$; step $300$ is explicitly a diagnostic with no gate, because an abstaining
writer has to learn \emph{where} to speak as well as what to say. We register the cheap failure mode
in advance: the least-effort policy under this mask is to emit filler everywhere, which is run 26,
scores $-0.74$ and buys nothing. Filler drives $\textsc{own}(1\text{--}11)$ to zero, so the gates
already exclude it---but if the run lands near zero the honest description is ``collapsed to
silence'', not ``failed to learn''. And as with run 31, clearing the final gate is break-even against
content-free filler, not a positive result.

\paragraph{A correction to the justification above, and the measurement it forced.} The appeal to the
abstention ladder in the preceding paragraphs is not quite valid, and the error is instructive enough to
keep. The ladder's interleaved-filler rungs blank their positions \emph{uniformly at random}, so the
true tokens that survive include content words; run 32's mask keeps a true token only where it is a
top-$300$ unigram, which is precisely the subset of tokens the reader can already predict. Same count,
a systematically less informative selection, and so the $+0.77$ rung was never a reference for the
target the run actually trains on. We noticed because the run's reader-side diagnostic---the gain of the
masked hint, whose content is fixed and not model-generated---reads about $-0.5$ where the ladder implied
$+0.5$ to $+2$. Measuring the rung the run actually trains, on run 32's own initialisation, at matched
count and matched length ($n=458$ anchors, paired), the cost of
using unigram frequency rather than a random selection of the same size is $-0.22 \pm 0.06$,
$-0.63 \pm 0.09$ and $-1.19 \pm 0.12$
nats at lengths four, seven and twelve: small at short lengths, where almost every token is frequent
anyway, and over a nat at twelve, where the mask strips the content words. At the full anchor count the
penalty is significant at \emph{every} length, including the seven the writer actually emits, where a
preliminary $n=37$ estimate had put it within noise; unigram frequency is a measurably bad selector, and
that penalty is the size of the prize for a better one. The run survives the
correction---at length seven the target is still
$+0.75 \pm 0.08$ above a blank slot of the same length, so its ceiling is above its floor---but two
lessons generalise. A ladder rung is a reference only for a target built the same way, and the length of
the supervised hint matters as much as its count: the trainer's hint is the thought's own trained length,
about seven, not the ladder's fixed twelve, which accounts for most of the gap between the diagnostic and
the rung we had quoted.

\paragraph{The step-300 diagnostic: the writer went silent, and the gate cannot tell silence from
failure.} Run 32's step-$300$ checkpoint was pre-registered as a diagnostic with no kill attached, and
we read it as one. Over positions one to eleven, measured against true held-out text at $n=616$ anchors,
the free-running thought's token agreement is $0.0323 \pm 0.0021$, against the $0.0722$ its first gate
demands at step $600$ and against the $0.0716$ its predecessor scored at the same step; the opening
token has halved, from $0.31$ to $0.151$; and the writer emits filler at $83\%$ of positions. On the
gate's own axis this is the registered failure mode, collapse to silence, arriving early.

The complication is that the gate's axis is not neutral between that failure and the treatment. Run 32
is \emph{trained} to emit filler wherever the true token is not a frequent unigram, so abstaining lowers
token agreement mechanically, and a writer that correctly declines to speak and a writer that has
stopped working drive the same number to zero. Decomposing agreement into a speaking rate and a
precision separates them: run 31 speaks at essentially every position and is right $0.072$ of the time,
while run 32 speaks at $0.173$ of positions and is right $0.187$ of the time when it does---one position
in six, at $2.6\times$ the accuracy. That is the design behaving as specified. Whether it is worth
anything is a question about value in nats against the filler floor, not about agreement, and value is
the axis on which runs 25, 27, 28 and 31 all failed.

We therefore registered a second instrument before step $600$ existed, and we state its terms here
because the discipline matters more than the result. The gate is not weakened: if run 32 clears it the
run continues regardless. If run 32 \emph{fails} the gate, it continues only if its own-minus-filler
value, paired per anchor against its own initialisation at matched anchors and register, is positive at
both four and eight tokens by more than two standard errors; otherwise the gate stands, the run stops,
and it is reported as a collapse to silence rather than as a near miss. An alternative axis adopted
after a gate's data arrives is an excuse; one registered before, which does not lower the original bar
and which demands a positive result on a harder instrument, is a measurement. Had those three
conditions not held, the right course would have been to let the gate end the run.

\paragraph{The first gate failed, and the baseline it was set from was too generous, not too harsh.}
At step $600$ run 32's free-running agreement over positions one to eleven is
$0.0397 \pm 0.0024$ ($n=616$, aligned register) against a gate of $0.0722$: not a near miss but a
factor of $1.8$, more than ten standard errors below the bar, and a trajectory---$0.0323$ at step
$300$---that would need to more than double again to reach it. We then measured the checkpoint the run
was actually initialised from, which had never been probed with this instrument: run 31 at step $800$
scores $0.0775 \pm 0.0032$, \emph{above} the $0.0722$ bar, which had been taken from run 31 at step
$600$. The gate was therefore set slightly below the run's own starting point, and run 32 at step $600$
sits at roughly half of it. We record this as a correction to our calibration and not as a rescue: had
the bar been set at the initialisation, as it should have been, the run would have failed it by more.
One caveat keeps the comparison honest in the other direction---run 31 terminates its thought from
position eight onward ($23\%$ of positions one to eleven carry its stop token), so neither writer is
attempting a forecast at all eleven positions, and both numbers are depressed by behaviour that is not
wrong guessing.

The treatment reading also sharpened, in both directions. Run 32's filler rate rose from $0.827$ to
$0.881$ and its stop token all but vanished ($0.068 \to 0.001$): it no longer ends its thought, it
fills it. On the one position in eight where it does speak, its precision rose from $0.187$ to
$0.335$---within reach of the $0.347$ that a \emph{teacher-forced} writer achieves on the same
instrument, which is the ceiling this project has been chasing for four runs. Those two facts are the
whole of run 32: it is becoming a better speaker and a rarer one at the same rate, and its agreement
falls because the second effect is larger.

\paragraph{A hole in our own registered rule, closed before its data arrived.} The value rule we
registered at step $600$ has a defect that its limit makes obvious: a writer that emits filler at every
position has own-minus-filler identically zero, so its improvement over an initialisation that was
$0.485$ below the floor is the largest possible pass. Total silence maximally satisfies the clause
written to rescue the treatment from the clause written to catch total silence. Since run 32 is moving
along exactly that axis, we amended the rule before the measurement existed, and only in the direction
that makes it harder: improvement over the initialisation remains necessary, and we add that the
thought must beat its own matched-length filler outright---the bar stated in
Section~\ref{sec:run26}---before the format may be described as buying anything. An improvement that
is only a retreat toward the control is to be reported in those words: it stopped harming, it did not
start helping.

\paragraph{The verdict: it stopped harming, and it did not start helping.} The amended rule was
answered at step $600$ on $465$ held-out anchors, paired against run 32's own initialisation
(run 31 @800) anchor by anchor. The necessary clause passed decisively and the sufficient one failed
decisively. Improvement over the initialisation is $+0.375 \pm 0.078$ at $m{=}4$ and
$+0.702 \pm 0.094$ at $m{=}8$, four and seven standard errors above zero: run 32 has removed most of
the harm that four previous runs did. But own-minus-filler \emph{itself} is $-0.110 \pm 0.030$ at
$m{=}4$ and $-0.132 \pm 0.033$ at $m{=}8$, three and four standard errors \emph{below} zero. The
thought is still worse than leaving the slot blank. Run 32 is the fifth checkpoint in a row to sit
below its own filler floor, and the first to come close to it.

Decomposing the improvement shows exactly what bought it, and the registered failure mode is half the
answer. At $m{=}4$, $230$ of the $465$ anchors have own-minus-filler identically zero---the writer
emitted filler and nothing else, so the two conditions are the same string---against $0$ such anchors
for its initialisation. Half of the gain is therefore mechanical: silence cannot harm. The other half
is not. On the $235$ anchors where run 32 does speak, own-minus-filler improved from $-0.322$ to
$-0.218$ at $m{=}4$ and from $-0.711$ to $-0.261$ at $m{=}8$ ($+0.450 \pm 0.122$, paired), so the
thoughts it does write are genuinely less damaging than the ones its initialisation wrote. Both
effects are real, and neither reaches zero.

The choice of \emph{where} to fall silent carries weak but consistent information. Measured on the
initialisation, the anchors run 32 learned to stay silent on were the ones where speaking had cost
most: $-0.653$ against $-0.322$ at $m{=}4$ and $-0.462$ against $-0.178$ at $m{=}2$. The sign is the
same at all four lengths, but the separation is $2.2$ and $2.1$ standard errors at $m{=}2$ and $m{=}4$
and only $1.3$ and $1.0$ at $m{=}8$ and $m{=}12$, so we record it as suggestive and not as
established. Where it does speak, its token agreement, $0.253$ at $m{=}2$, is what its initialisation
achieved everywhere; where it is silent, agreement is $0.017$, the base rate. Run 32 has learned to
partition anchors into ones it treats like run 31 and ones it declines, and it picks the partition a
little better than chance. That is anchor-level gating, whose ceiling we registered in advance as
break-even rather than positive, and the run landed inside it.

We therefore stopped run 32 at step $1130$ on the hard stop registered at $1000$, and we withdraw its
step-$1000$ agreement gate of $0.105$ explicitly as unreachable rather than let it pass unmentioned:
the run's agreement was falling by design, and a gate the treatment cannot reach is not a gate.

\paragraph{Which token should a thought spend its budget on?} Run 32 chose \emph{where} to speak by
unigram frequency, and the count-matched control says that choice was the weak part of the design
rather than the format: at a matched number of surviving true tokens, frequency selection is worse
than selecting positions at random by $-0.224 \pm 0.056$, $-0.630 \pm 0.094$ and $-1.188 \pm 0.122$
nats at $m{=}4$, $7$ and $12$. The mask keeps the tokens the reader can already predict. The obvious
repair is to select by the model's own confidence, which is a good selector of where it is right
($0.713$ at four positions of twelve against $0.442$ unselected)---but confidence is a
\emph{better} proxy for what the reader already predicts than frequency is, so the objection that sank
frequency may apply to it with more force. We register the two measurements that decide this before
either has run: a count-matched ceiling comparing true tokens placed at the most confident against the
least confident positions, and the same comparison priced at the writer's real accuracy, using the
token it would actually emit rather than the true one. The achievable number overrides the ceiling
where the two disagree, and if neither construction clears the filler floor we will report
position-level selection as closed rather than look for a third selector.


\paragraph{The answer, at full sample: confidence is not the selector, and the writer cannot collect
what is.} The ceiling comparison was run on run 32's own initialisation, on the same $465$ anchors as
the frequency measurement, so all four selectors differ only in which positions survive. The
registered gate---confidence-selected minus frequency-selected at $m{=}7$, the length the writer
actually emits---is $+0.021 \pm 0.066$. It fails. Worse for the repair, confidence-selected true
tokens lose to a count-matched \emph{random} mask by $-0.609 \pm 0.087$, almost exactly the penalty
frequency selection carries ($-0.630 \pm 0.094$): the two selectors fail for the same reason and to
the same degree, and the reason is the one we registered in advance. Both keep the tokens the reader
was going to predict anyway. The opposite selector is where the value sits: true tokens at the
\emph{least} confident positions beat a blank slot of the same length by $+2.014 \pm 0.119$ nats and
beat the random mask by $+0.650 \pm 0.109$. That is a ceiling, not a capability---it places the
\emph{true} token at exactly the positions where the writer's own argmax is least often right---and
the matching achievable measurement, which prices the same comparison with the token the model would
really emit, is the one that decides whether position-level selection is closed. It closes it. At the
writer's own accuracy the least-confident positions are right $0.207$ of the time against $0.718$ at
the most confident---an arithmetic prediction of $0.21$ that we registered before writing the
code---and the construction that commits there scores $-1.79 \pm 0.13$ against $-1.53 \pm 0.13$ for
its confident counterpart, with the filler floor at $-1.28$ above both. Every width tells the same
story: the information does live in the positions the model is least sure of, and the writer cannot
deliver it. We therefore report position-level selection as closed, in both directions, rather than
look for a third selector, and we note that the same split holds on the mathematics domain as on
web text.

\paragraph{Run 32 at step 1000: flat.} The step-$1000$ reading, paired against both the step-$600$
reading and the initialisation on the same anchors, moves the verdict not at all: own-minus-filler is
$-0.130 \pm 0.033$ at $m{=}4$ and $-0.148 \pm 0.034$ at $m{=}8$, and the paired change over the $400$
intervening steps is $-0.020 \pm 0.033$ and $-0.016 \pm 0.036$. The quantity did not asymptote toward
zero from below; it asymptoted below zero. The one column that moved is $m{=}12$, by $+0.107 \pm
0.041$, and it moved for a reason opposite to the silence artefact: the stop token returned between
the two checkpoints, the count of anchors where the twelve-token draft is pure filler fell from $230$
to $71$ of $465$, and on the $224$ anchors that speak at both steps the improvement is $+0.177 \pm
0.069$. The writer learned to end its thought, and its endings are less damaging than its
initialisation's.

\paragraph{The term we have never attacked.} A thought's value against no thought at all decomposes
into two parts: what the block costs merely by being spliced in, and what the thought says on top of
that. Every run in this paper has attacked the second. On run 32 at step $1000$ the first is
$-0.769$ and the second is $-0.130$; on the inference instrument the same split reads $-0.736$
against $-0.433$ for run 25 at step $900$, $-0.503$ against $-0.354$ for run 27, and $-1.612$ against
$-0.639$ for run 30. Between three-fifths and six-sevenths of the deficit is the price of the slot,
not of its contents. That price is not a constant: run 32 raised its own filler level over its
initialisation by $+0.501 \pm 0.065$ while training a writer, and run 26---which spent $1500$ steps
with a filler block at every anchor and differs from run 25 only in that flag---pays
$-0.083 \pm 0.021$ for its block against its sibling's $-0.736 \pm 0.087$, on the same instrument and
the same anchors. Five times the entire gap run 32 closed, on the term nobody was watching.

We register the fork before its data, because the cheap block admits two readings and they imply
opposite actions. Either the cost is ordinary distributional novelty, in which case a reader can be
made to carry the block for free \emph{and} still hear a real hint; or the cost is what a reader pays
to attend to the block at all, in which case cheapness is deafness, the two are one parameter, and
the correct output of this programme is the negative result rather than another run. The discriminator
is the value of a perfect hint to run 26's reader, against the $+10.72$ nats the same hint is worth to
its sibling: at or above half of that, the first reading; below a third of it, the second. We also
register the feasibility question that follows a favourable answer---whether a checkpoint can hold
both a writer and a nearly free block---and will read it from run 32's own weights on the instrument
that carries the four published numbers above.

\paragraph{The fork resolved: the cheapest block we have sits under the most sensitive reader we
have.} Both registered files returned at full sample. Run 26's reader---which saw nothing but
content-free filler in the thought slot for $1500$ steps---values a perfect twelve-token hint at
$+12.62 \pm 0.42$ nats, against the $+10.72$ the same hint is worth to its sibling on the matched
instrument and register. The registered thresholds were half of that reference for the first reading
and a third for the second; the measurement is \emph{above} the reference, and the whole ladder
descends in order behind it ($+8.02$, $+6.39$, $+4.38$, $+2.73$, $-0.67$, $-4.41$ at offsets
$8$ to $64$, and $-1.45$ for the same hint shuffled), so the sensitivity is to content at the right
offset and not a level shift. A reader can be made to carry the block nearly for free and still hear
a real hint perfectly well. Cost and sensitivity are not one parameter, and the reading on which
this programme's correct output was a negative result is falsified. We note that this retracts our
own earlier suggestion in the other direction: run 26's reader scores $-10.36$ when fed a written
thought, which we flagged at the time as register shock rather than evidence, and the true-hint
ladder confirms that reading. The same reader's break-even against its own floor is $2$ correct
tokens of twelve---the lowest we have measured.

\paragraph{A writer does not get the cheapness for free.} The feasibility half is less encouraging.
Run 32 at step $1000$, probed on the instrument that carries the published filler numbers, pays
$-0.926 \pm 0.095$ for its block: the worst of the three registered bands, and worse than three of
the four checkpoints it was to be compared against. Ordered on one instrument and one set of $465$
anchors, the price of the slot is $-0.083$ for run 26, $-0.503$ for run 27, $-0.736$ for run 25,
$-0.926$ for run 32, and $-1.612$ for run 30. Eleven hundred steps of training a writer did not
produce the regime that made run 26's block nearly free. The headroom on this axis is therefore
about $0.84$ nats, six times the content gap run 32 closed, and it is available only to a run that
deliberately trains for it.

\subsection{Run 33: making the block free}
\label{sec:run33}

Run 33 is run 32 with one flag added: a fraction---one half---of the anchors carry run 26's
content-free filler instead of a written thought. Those anchors leave both writer objectives, so no
imitation and no policy gradient reaches their block rows, and they join the reader's objective, so
the reader is trained to predict the true continuation across a block that says nothing. This is run
26 at fraction one and run 32 at fraction zero, in one run and on one set of weights; the writer
keeps the other half of the anchors and therefore receives half the gradient per step, so its
trajectory should be read against run 32's at half the step count.

We state the limit of this design before its data, because it is the conclusion a later reading
would otherwise mistake for a success. Our bar is a thought's value \emph{minus} filler's value on
the same weights, and the cost of the block is precisely the term that cancels in that difference.
If run 33 does exactly what it is built to do---the block's price falls from $-0.93$ to $-0.08$ while
what the thought says stays where run 32 left it---then the absolute quantity improves from $-1.13$
to $-0.28$ and the bar is still failed by the same $-0.20$. The run buys the secondary,
absolute measurement outright. It reaches the primary one only if a further proposition is true,
which we have not measured: that the content term is negative \emph{because} the reader is in a
high-surprise regime, so that a reader which pays nothing to read the block can also use what is in
it. That proposition is the real question of run 33, and the run is gated on it rather than on the
block price. Two mechanism gates check that the flag does what it claims---a paired improvement of
at least $0.30$ nats over the initialisation's $-0.926$ by step $400$, and $0.55$ by step $800$,
the first derived from run 26's own curve at fraction one---but an own-minus-filler reading at step
$800$ that is worse than the initialisation's stops the run regardless of how far the block's price
has fallen. That combination, mechanism gates passing while the bar moves backwards, is the failure
mode we expect if it fails: a reader can make the block free by learning to ignore it, which would
make the block free by making the writer irrelevant. Run 26's undiminished sensitivity says this is
not forced, but run 26 never had a writer competing for the slot, so it does not rule it out.

The gate that overrides the other two now has a number, measured after the run was launched and
registered before the checkpoint it judges existed. Run 32's final weights had never been put
through the inference instrument with a written thought: only the filler arm had been run, so the
difference the bar is written in did not exist for this lineage. Both arms are now complete on the
same $465$ anchors, and paired per anchor they give a block price of $-0.926 \pm 0.095$, a written
thought at $-1.127 \pm 0.111$, and an own-minus-filler of $-0.200 \pm 0.042$, four and a half
standard errors below zero, with the thought helping on $43\%$ of anchors and its greedy decode
running $10.5$ tokens against the filler's $10$. Run 33 at step $800$ must not fall below that
$-0.200$ by more than one standard error of its own paired difference.

We record the size of the correction this forces, because it runs against us. Run 32's content term
has been quoted throughout at $-0.130 \pm 0.033$, which is what the teacher-forced draft probe reads
at a four-token prefix; at the ten tokens the model actually emits, on the instrument the bar is
written in, it is $-0.200 \pm 0.042$, half as large again. Harm grows with length on every
checkpoint we have measured, so the two readings are the same curve at two points rather than a
contradiction---but the honest headline figure for run 32 is the larger one, and the verdict it
carries is unchanged. It is the sixth checkpoint in this paper to sit below its own filler floor,
and the first to be placed there by the instrument that decides the question.

The first mechanism gate has now been read, and it passes. At step $400$, on the same $465$ anchors
and paired per anchor against the initialisation, the block's price is $-0.551 \pm 0.082$ against
$-0.926 \pm 0.095$: a paired improvement of $+0.376 \pm 0.053$, seven standard errors from zero,
cheaper on $63\%$ of anchors individually, at a matched filler length of ten tokens on both sides.
The gate asked for $+0.30$, derived from run 26's own curve at fraction one and set deliberately
below the expectation so that it would falsify a dead mechanism rather than a slow one; the
measurement clears it by one and a half standard errors. Four hundred steps at fraction one half
have closed about $45\%$ of the $0.84$ nats that separate run 32's block from run 26's---above the
$36\%$ the gate demanded and below the $65\%$ the derivation expected, so the mechanism is live but
running under the pace that the fraction-scaling argument assumed, and the step-$800$ gate at
$+0.55$ is not already in hand. The flag does what it claims.

We say plainly which of the two terms this is, because the distinction is the one this section was
written in advance to protect. It is the filler term alone---the price of the slot, measured with
nothing in it---and that term cancels in the bar. What the thought \emph{says} was not measured at
step $400$ by the gate, and nothing here yet speaks to the proposition the run is really about.
A reader that has learned to pay less for an empty block may or may not have learned to use a full
one, and the measurement that separates those is the own-minus-filler reading at step $800$. Until
that lands, the honest statement of run 33's position is that it has made the slot cheaper by
$0.38$ nats and has said nothing whatever about whether a thought is worth having in it.


The step-$800$ gate has now been read, and it fails. On the same $465$ anchors, paired per
anchor against the initialisation, the block's price at step $800$ is $-0.664 \pm 0.081$: a
paired improvement of $+0.262 \pm 0.048$ against a registered bar of $+0.55$, six standard
errors below it. The failure is not slowness but reversal---the same gate read $+0.376 \pm
0.053$ four hundred steps earlier, so the mechanism peaked at step $400$ and then went
backwards, ending at $0.26$ of the $0.84$ nats available rather than heading for run 26's
$-0.083$. Run 33 was stopped at step $899$ on that clause.

The value gate fails too, and the reason it fails is a defect in the instrument that we
report here because it retires a number this paper has been quoting. The control condition of
the think-mode probe is a run of space tokens followed by the closing marker. On this lineage,
so is the model's greedy thought: every greedy thought we dumped from run 32 @1000 and run 33
@400 and @800 is the space token repeated and then the marker, at mean lengths $10.45$,
$13.42$ and $13.93$ against a fixed control of ten. \emph{The two conditions are the same
string at different lengths}, so their difference measures filler length, not content, and it
decomposes exactly that way. Binning run 32 @1000 by its own greedy length against the
ten-token control gives $+0.023$ at eight tokens, $-0.131 \pm 0.089$ at ten---matched, and
indistinguishable from zero---and $-0.498$ and $-0.656$ at thirteen and fourteen, with a
correlation of $-0.27$ between length and harm. \textbf{At matched length run 32 has no
measurable content effect at all}, and the $-0.200 \pm 0.042$ we reported for it is about
two-thirds an artefact of writing eleven spaces where the control writes ten. Run 33 @800
reads $-1.147 \pm 0.284$ on the same comparison, and the same decomposition applies with more
force: $390$ of $465$ anchors emit fourteen or fifteen tokens, costing $-0.494$ and $-1.201$
respectively, and three anchors reach the sixteen-token cap where the thought never closes
and cost about $66$ nats each, which is what inflates the standard error. Trimmed of those,
run 33 @800 is $-0.719 \pm 0.067$. What run 33 actually did to its writer is lose the stop
action: greedy length $10.45 \to 13.9$ under half the writer gradient. Two things follow. The
block's price is steeply superlinear in length---pure whitespace at fourteen tokens costs
$-0.49$ and at fifteen $-1.20$ against the same ten-token control on the same weights---and
value on an abstaining lineage must be read from the draft probe, whose filler is
length-matched at every prefix by construction, never from the think-mode probe's greedy arm.

The deeper consequence is about run 32, and it is a correction against us. Abstention writes
filler into the imitation \emph{target} wherever the true token is not among the three hundred
most frequent unigrams, which is about $45\%$ of positions, so the writer is trained to emit
filler as an action---and it over-generalised. Its filler rate over positions one to eleven is
$0.83$ at step $300$, $0.88$ at $600$ and $0.74$ at $1000$, against $0.025$ for run 31 @800,
which is run 32's own initialisation. Run 32's registered failure mode was collapse to
all-filler; it happened, the decision rule we use for value is maximised by exactly that
collapse, and the greedy arm of the inference probe is blind to it. \textbf{``Run 32 stopped
harming'' is more honestly read as ``run 32 stopped speaking''.} What it genuinely bought is
narrower and survives: where it does speak it is four times more accurate than any writer this
project has trained, precision rising $0.187 \to 0.335$ against the teacher-forced ceiling of
$0.347$.

\subsection{Run 34: is a spoken token worth more than a blank one?}
\label{sec:run34}

Run 34 asks the question the previous paragraph exposes, and it is the sharpest form in which
this programme's central proposition can be put: \emph{is a token the model chooses to write
worth more, to the same model reading it, than leaving the position empty?} Run 32 scored
$-0.110 \pm 0.030$ at a four-token prefix by saying almost nothing; run 31, speaking at every
position with a precision of $0.080$, scored $-0.485 \pm 0.080$. Neither is the interesting
cell. The interesting cell is a writer that speaks \emph{and} was trained only on targets it
can reach, and no run has occupied it.

One flag differs from run 32, and the initialisation is run 32's own, so run 32 is a matched
control at every step rather than an ancestor. The abstention mask is unchanged---blanks still
occupy their positions in the block the model reads, so the format the reader was shown is
identical---but the blanked positions now carry no weight in the imitation loss. Silence stops
being a supervised action, and the imitation gradient survives only where the true token is
reachable: the lesson of runs 24--27, that a writer trained on an impossible target learns a
register instead, applied at the level of positions rather than offsets. We leave the loss
normaliser untouched so that the surviving positions carry exactly the weight they carried in
run 32.

The gates are registered before any data exists and fire themselves. At step $300$ the
mechanism gate asks only whether the flag did anything: the filler rate over positions one to
eleven must fall below $0.50$, against $0.83$ for run 32 at the same step and $0.026$ for the
initialisation. At step $600$ the primary gate has two clauses and both are required. The
first is that the writer is not silent---the same filler-rate bound---and it is there because
the second clause is \emph{maximised} by total silence, which scores exactly zero on it; we
have made this mistake once already and write the defence in advance now. The second is that
own-minus-filler at four- and eight-token prefixes, on the length-matched draft probe, is no
worse than run 32's $-0.110$ and $-0.132$ by more than two standard errors of run 34's own
paired difference. At step $1200$ the decision gate is the success bar of Section~\ref{sec:run26}
itself, own-minus-filler above zero, which no run in this paper has cleared.

We also register how to read the outcome. If run 34 speaks and lands at run 32's level, then
content is finally free and the programme continues. If it lands between $-0.110$ and
$-0.485$, precision did not survive volume, run 32's $0.335$ was a selection effect of
speaking rarely, and the negative result of this paper is complete in its strongest form: not
merely that our writers are inaccurate, but that at this scale a token the model chooses to
write is worth less to it than a blank.


\paragraph{Verdict: the flag worked, the writer spoke, and speaking cost it.}
Run 34 was stopped at step $886$ on the step-$600$ gate. The mechanism clause passed twice and
by a wide margin: the filler rate over positions one to eleven is $0.046$ at step $300$ and
$0.043$ at step $600$ ($n{=}616$ anchors, the same instrument and invocation as every control),
against $0.827$ and $0.881$ for run 32 at the identical steps and $0.026$ for the shared
initialisation. Removing the loss weight on the blanks does exactly what it was built to do:
the writer speaks again, at its initialisation's volume rather than run 32's, and it is not
merely louder---the opener recovers to $0.266$ against run 32's $0.164$, and the teacher-forced
ceiling inside the slot is undamaged.

The value clause failed, and not narrowly. On the length-matched draft probe ($n{=}465$, paired
per anchor) run 34 at step $600$ scores $-0.520 \pm 0.067$ at a four-token prefix and
$-0.892 \pm 0.083$ at eight, against bars of $-0.110$ and $-0.132$: six and nine standard errors
below, where the gate allowed two. It is not merely worse than the mute run 32; it is worse than
run 31, the fully speaking control that is also its own initialisation ($-0.485 \pm 0.080$ and
$-0.834 \pm 0.096$). Six hundred steps of training a writer only on reachable targets left it
speaking as much as when it started and worth slightly less.

The decomposition says why, and it is the registered reading rather than a new hypothesis.
Writing own-minus-filler against the rate at which the writer emits a non-blank token gives
three points on one line: run 32 speaks at $0.119$ and scores $-0.110$, run 34 at $0.957$ and
scores $-0.520$, run 31 at $0.975$ and scores $-0.485$. Value is a function of \emph{how much is
said}, at roughly half a nat per unit of speaking rate at a four-token prefix, and the fourfold
precision advantage run 32 held where it did speak ($0.335$ against run 34's $0.062$ and run
31's $0.080$) contributes nothing detectable to it. Run 32's precision was a selection effect of
speaking rarely, on the positions where speaking was easy; asked to speak everywhere, the same
format and the same loss produce a writer no more precise than the one that never abstained.
Run 34 is in fact the \emph{more} accurate writer by the draft probe's own token agreement at a
four-token prefix ($0.149$ against run 32's $0.089$), which makes the point sharper: more true
tokens in true positions, and less value.

\paragraph{The headline instrument agrees, and on this lineage it can be trusted.} The value
clause above is read on the length-matched draft probe, because on the abstaining runs 32 and 33
the greedy thought \emph{is} the filler string and the think-mode probe's own-minus-filler
contrast degenerates into a comparison of two fillers at different lengths (Section~\ref{sec:run33}).
Run 34 removes that objection by construction: its greedy thought is ordinary text at $96\%$ of
positions, so the two arms differ in content and not only in length. On its final checkpoint
(step $800$, $n=465$ anchors, filler length matched to the writer's $9.0$ greedy tokens) the
model's own thought scores $-1.500 \pm 0.123$ nats and content-free filler on the same weights
$-0.688 \pm 0.093$: own-minus-filler is $-0.812 \pm 0.082$ paired per anchor, ten standard
errors below zero, and $-0.687 \pm 0.169$ on the $93$ anchors where the thought is exactly nine
tokens long. Sampled thoughts are no better ($-0.765 \pm 0.089$). The instrument that names the
project's bar and the instrument that decided the gate agree, and the last checkpoint of the
programme sits further below its own filler floor than any checkpoint before it whose thought
was made of words.

This is the outcome registered in advance as completing the negative result, and we report it in
that form. At this scale, in this slot, the proposition is not that our writers are too
inaccurate to be useful---it is that a token the model chooses to write is worth less to it than
a blank, that the deficit scales with how often it chooses to write one, and that the one design
that scored well on the value instrument did so by falling silent. We stopped the run rather
than spend the remaining $900$ steps confirming it, and we did not launch a successor on this
axis.

\subsection{What the previous approaches established}
\label{sec:established}

 The eighteen runs recorded in Appendix~\ref{app:previous} produced one robust quantitative fact and one qualitative change, and the programme of Section~\ref{sec:programme} is built on both. The fact: wherever the reader functions at all, the order-borne value of an immature policy's own thoughts is a small negative constant, invariant to every lever we can pull---base maturity ($0.87 \to 8.99$B tokens), reward horizon ($k{=}8 \to 64$, and a curriculum between them), search width ($R{=}1 \to 8$), and reward density (a gate firing on nothing, made dense). Four configurations differing in all of these agree on $-0.07$ to within one standard error. That is not a tuning failure; it is a property of the regime.

The change is that this constant was measured under designs in which the model was permitted to decline, and it now appears the constant partly \emph{describes the declining}. Removing the option---compulsory thinking, Section~\ref{sec:procedure}---changed what can be measured: the reader now responds to the structure of a thought (early in every pilot a scrambled thought costs it many nats more than the ordered one), and the selected thought beats its own shuffle. It also changed what we can \emph{not} measure without one more pass: the pilots score only the winner's shuffle, so neither of their order-borne quantities is unbiased (Section~\ref{sec:rollouts}). The next question is therefore narrower than the one we started with: not \emph{can a thought be worth anything}, which four configurations answered with a flat no, but \emph{does an ordered thought's advantage over its own shuffle survive once the reader has learned to tolerate disorder}---in every pilot that margin shrinks, and the programme instruments the non-selected shuffle to say whether it shrinks to the invariant or above it.

We are also explicit about a contamination risk the mixed-anchor design introduces, which cost us nothing only because it was caught immediately: with supervised and reinforcement thoughts sharing a sequence, any dump that selects by gain will overwhelmingly return supervised anchors---which hold the true continuation verbatim---and present ground truth as the model's own reasoning. Every dumped record now carries its provenance, and no claim about what the model writes is made from an untagged one.


\section{Our own mistakes, and the measurement that caught each}
\label{sec:mistakes}

Every item here produced healthy-looking training curves while being wrong, which is the reason the instruments of Section~\ref{sec:instruments} exist. We report them because each is a plausible default that another group would make.

\begin{enumerate}
\item \textbf{bf16 parameters froze half the network.} With plain AdamW and no fp32 master copy, round-to-nearest discards any update smaller than half a ULP: at $\mathrm{lr}=5\times10^{-5}$ that is every weight with $|w| \ge 2^{-6}$---$52\%$ of the query projections, $42\%$ of the MLP down-projections, $64\%$ of the output head, and every normalisation gain, which were bit-identical to initialisation after thousands of steps. Runs 15--18 therefore trained the small half of every matrix at a rate that was never the nominal one. \emph{Caught by} comparing checkpoint tensors against the initialisation.
\item \textbf{Fixing it exposed a learning rate that had never been tested.} With every weight finally moving, $5\times10^{-5}$ destroyed the base: held-out cross-entropy $2.786 \to 3.351$ in $2{,}300$ steps, monotone, while every thinking observable looked healthy. \emph{Caught by} the held-out ruler, which we had not been running in the loop and now run on every checkpoint. The training loss did not show it: it is measured on a deterministic batch stream whose difficulty varies with the step.
\item \textbf{We supervised the writer on a target the reader values below silence.} For three billion tokens the supervised thought was the span \emph{beyond} the scored window. \emph{Caught by} the oracle-offset probe, which placed the value of a hint at $0$--$32$ tokens ahead and $-1.6$ at our target.
\item \textbf{An offset lottery made the target unlearnable by construction.} Drawing the supervised span's offset uniformly from $\{0,\dots,4\}$ per anchor, invisibly to the writer, caps first-token agreement at (top-1 accuracy)$\,\times\,1/5 \approx 0.09$; we measured $0.113$ and had been reading it as a capability. \emph{Caught by} the arithmetic, prompted by an imitation cross-entropy that plateaued $0.70$ nats above the clean next-token loss within a hundred steps---an ambiguity floor, not a learning curve.
\item \textbf{The thought sat one position out of register} (Section~\ref{sec:slotpos}): $0.85$ nats. \emph{Caught by} scoring one buffer under two position vectors.
\item \textbf{The reader was trained on a diet it never gets at inference}, and learned to trust hints (N4). \emph{Caught by} the think-mode probe disagreeing with the training-time gain.
\item \textbf{Pure teacher forcing in the thought slot} meant the writer never trained in the regime it samples in (N5). \emph{Caught by} the teacher-forced-slot probe.
\item \textbf{Best-of-$R$ contaminated the reported numbers} until we separated them: the winner of eight rollouts is inflated by $\approx 1.4$ standard deviations on noise alone, and for several runs we compared the mean rollout against the \emph{winner's} shuffle, a difference biased negative. Every order-borne number in this paper is now the unselected rollout against its own shuffle.
\end{enumerate}

\section{What would have to be true for this to work}
\label{sec:whatwouldwork}

We state these as quantities, because each is now measurable in an afternoon.

\paragraph{The writer must be right more often than it is confidently wrong.} The reader pays $+8.9$ nats for a correct $12$-token hint and charges about $-1$ for a plausible wrong one. At the measured free-running agreement of $0.06$, the expectation is negative; the break-even is roughly a quarter of the tokens correct, which is where the model already is \emph{teacher-forced} ($0.30$). Closing the free-running gap is therefore the one change with a clear path to a positive number, and it is a known problem with a known family of fixes (scheduled sampling, DAgger). We applied them and they did not work: run 30 ran scheduled sampling together with the position fix and finished below its own matched control (Section~\ref{sec:run30}), and runs 31, 32 and 34 closed the remaining readings of the gap without moving free-running agreement off its floor. The quantity is still the right one to name; we have no mechanism that moves it.

\paragraph{Or the thought must be short enough to be right.} Damage grows with length: own-minus-filler goes $-0.11$ at two tokens to $-0.70$ at twelve. A two-token thought is nearly free; a two-token \emph{correct} thought is worth $+1.0$. Short thoughts turn the problem into one the model can almost solve.

\paragraph{Or the model must decline to think when its thought is bad.} About a fifth of unselected thoughts already beat silence, and a model that could sort its own thoughts into keep and discard would exploit that variance rather than fight it. We have since priced the ceiling, and it is lower than this paragraph originally claimed: on run 31 @800 the per-anchor correlation between agreement and own-minus-filler is only $r = +0.180$ at $m=2$, and the top agreement quartile---the anchors a perfect oracle gate would keep---scores $-0.082 \pm 0.105$, i.e.\ break-even, not positive (Section~\ref{sec:run31}). Perfect anchor-level gating buys the right to stop losing; a realistic selector captures a fraction of that. The sorting mechanism is sound and the thing being sorted is not yet worth keeping.

\paragraph{Or the scale must be larger.} The reader's capacity ($+11$ nats) is enormous compared to anything the writer produces, and writer accuracy is exactly the quantity that improves with parameters and tokens. We cannot test this on one node; we can say precisely what to measure if someone does: free-running agreement at the first thought token, own-minus-filler at $m=2$, and the think-mode probe.

\section{Related work}
\label{sec:related}

\paragraph{Quiet-STaR.} \citet{zelikman2024quietstar} train a model to generate a thought at every token position, reward thoughts by the improvement in log-likelihood of subsequent true tokens, and combine predictions through a mixing head. Our objective descends from theirs. The differences: we train the base from scratch and introduce thinking at chosen ladder rungs; thoughts sit at a fixed stride of $64$ tokens (and, in phase C, at a fixed budget of positions the model ranks) rather than at every token; the reward horizon is long and discounted, with an explicit anti-copy analysis; the writer is anchored by permanent imitation of the true continuation at a quarter of the anchors and explores with advantage-weighted REINFORCE over $R$ rollouts at the rest; there is no learned mixing head, the reader simply attends to the thought; and every claim about content is checked against a token-shuffled minimal pair of the same thought. Quiet-STaR's setting (a mature pretrained model, $k \le 8$, thoughts at every position) sidesteps the cold-start, copying, and collapse failures that dominate ours.

\paragraph{Pause tokens.} \citet{goyal2024think} insert learnable contentless tokens that give the model extra forward passes without content. Filler thoughts (Table~\ref{tab:oracle}, row 5) are our built-in version of this control, and run 26 is the full training arm: $1{,}500$ steps in which every anchor carries content-free filler and no thought is ever written, from the same initialisation as its sibling run 25 (Section~\ref{sec:run26}). It separates the value of extra computation from the value of generated content, and at this scale the computation is all of it: filler beats the written thought on the same weights at every block and every length we have measured.

\paragraph{STaR.} \citet{zelikman2022star} bootstrap reasoning by sampling rationales on question--answer pairs and finetuning on those that lead to correct answers. Our distillation estimator is STaR-shaped, but unsupervised: ``correct'' is replaced by the counterfactual gain of Eq.~\eqref{eq:gain}, and our run-8 collapse is the failure mode of STaR-style imitation when the eligibility signal is too weak---hence the speculation margin and the floor.

\paragraph{Latent-space reasoning.} Coconut \citep{hao2024coconut} feeds hidden states back as inputs, reasoning in a continuous latent space with exact gradients. We keep thoughts discrete because shared vocabulary tokens leave open the possibility of readable thought---and our first free-form samples are, in fact, readable.

\paragraph{Reinforcement learning on pretraining data.} A recent line of work applies reinforcement-style objectives at pretraining scale, rewarding intermediate generation by its effect on the likelihood of subsequent text \citep{nvidia2025rlp}. These methods begin from pretrained or mid-trained checkpoints; the ladder protocol extends the question to younger models.

\section{Limitations}

All results are at 0.6B parameters, at most $12$B tokens, one node, and a $16$-token thought at a $64$-token horizon; the benchmarks show a model that knows facts and cannot reason, and a thought can only be about what the model can represent. The negative results are therefore statements about this regime, and N1 (the reader's capacity) is what makes us think the regime, not the idea, is what fails.

Placement is ours, not the model's: thoughts sit on a fixed stride and are compulsory. Every earlier design that let the model decide \emph{whether} to think collapsed to never thinking, which is why the option was removed; a budget that forces the model to choose \emph{where} rather than \emph{whether} is designed (Section~\ref{sec:budget}) and not yet run, because it is pointless while no thought has positive value anywhere.

The compute overhead is architectural: a step is dominated by the sequential decode of $L$ thought tokens, each a dispatch-bound device launch, so cost scales with thought length rather than with the number of thoughts, and a thinking step is about $4\times$ a vanilla one. Every ``expected speedup'' we projected before measuring was wrong, and we report only measured ones.

Finally, the filler control deserves its own caveat and its own emphasis. Run 26 trains the reader on $100\%$ filler anchors against run 25's $75\%$, an asymmetry that favours the control; it is far too small to explain $1.5$ nats, but it is real. In the other direction, the same control is the reason we can say anything at all about what our thoughts are worth: without it, run 25's halving of the cost of thinking would have read as progress toward thinking, when it was progress toward not being hurt by it.

\subsection{Positional encoding: the negative result}
\label{sec:positions}

Thought tokens need positions. Assigning ordinary sequential positions would shift all subsequent real tokens, so the same document would receive different positional geometry depending on whether the model thought. Our original design gave thought token $i$ the fractional position $n + i\varepsilon$ with $\varepsilon = 1/(L_{\max}+2)$, placing the thought strictly inside the interval $(n, n{+}1)$; rotary embeddings \citep{su2021roformer} accept fractional values without modification.

\textbf{This design fails, and the failure is invisible without the right measurement.} Training with fractional positions produced flat or negative rewards for six consecutive runs. The diagnosis came from an \emph{oracle ceiling test}: teacher-force the true window tokens in as the thought---the most informative thought that could exist---and measure Eq.~\eqref{eq:gain}. If even the oracle cannot produce positive gain, no learned thought can, and the run is doomed before it starts. Table~\ref{tab:oracle} shows the result on the 372M-token base checkpoint ($L{=}k{=}8$, 102 slots): with fractional positions the oracle gains $-1.3$ nats (win rate 36\%); the same oracle content at \emph{integer} positions gains $+8.2$ nats (win rate 90\%). A model pretrained on integer RoPE geometry simply cannot read content placed at sub-integer offsets it has never seen; the information is there, the attention geometry is not.

\subsection{What failed, and what each failure bought (runs 1--12)}
\label{sec:failures}

Training thoughts from scratch failed in five distinct ways before it worked in any. We report them because each one is a plausible default choice, each produced healthy-looking training curves while being degenerate, and each maps to a specific mechanism in Section~\ref{sec:method} or Appendix~\ref{app:superseded}.

\paragraph{Fractional positions (runs 1--6).} Described in Appendix~\ref{sec:positions}. Six runs of flat reward, diagnosed in one afternoon once the oracle ceiling test existed. \emph{Lesson: measure the ceiling before training toward it.}

\paragraph{The myopic window optimum is copying (run 7).} With $k = 8$ and integer positions, Stage-A training (gate and reader learning, writer lightly trained) succeeded at its stated goal: the gate learned to open for oracle thoughts ($w_{\mathrm{or}} \approx 0.85$) while sampled thoughts sat at a neutral 58\% win rate, and oracle gains reached $+35$--$40$ nats. But inspection of high-reward sampled thoughts showed fragments of likely continuations---the beginnings of verbatim copies. The $k \le L$ analysis of Section~\ref{sec:gain} was written after observing this. \emph{Lesson: the horizon, not the reward scale, decides what the objective means.}

\paragraph{Naive self-imitation mode-collapses (run 8).} Distilling the best-of-$m$ thought without the floor of Eq.~\eqref{eq:elig} entered a ratchet: a mildly successful thought became more probable, was sampled and won again, and within ${\sim}100$ steps the policy emitted one universal thought at every anchor (its cross-entropy on its own samples $\to 0$; all rollouts identical; selection dead). The run was cut at step 464. \emph{Lesson: imitate only what the policy does not already know---hence the floor $F$.}

\paragraph{Negative controls can be gamed (run 8).} Our first negative probes were \emph{shuffled} windows: the true window's tokens in random order. The reader learned to exploit them as a bag of words ($+8$--$15$ nats---unigram evidence about the future leaks through a shuffle). Random-token negatives (Table~\ref{tab:oracle}, row 4) close the leak. \emph{Lesson: a control must carry zero information, not merely scrambled information.}

\paragraph{First signs of discrimination (run 9).} With random negatives, exploration temperature, and the distillation floor in place, the gate showed the first content discrimination we observed: $w_{\mathrm{ng}}$ fell from $0.68$ to $0.42$ over 350 steps while $w_{\mathrm{or}}$ stayed ${\approx}0.99$. Thoughts, however, remained short fragments (\texttt{1 and even; the so be in})---consistent with the myopic-horizon analysis, and the direct motivation for the long-horizon run of Appendix~\ref{sec:think10}.

\paragraph{A purely relative baseline is exploitable by adversarial noise (run 10a).} Our first long-horizon run used the speculation margin and the floor of Eq.~\eqref{eq:elig} but \emph{not} the absolute condition: a thought was imitated whenever it beat the greedy guess by $\varepsilon$, regardless of whether it helped at all. Within 200 steps this produced a new degeneracy (Figure~\ref{fig:run10a}). Early in training \emph{every} inserted thought hurts the window, but not equally: a fluent-but-wrong thought actively misleads the reader, which attends to it and follows, while word salad is easy to ignore. ``Less damaging than your own fluent guess'' is therefore won by \emph{weirdness}. Distilling those winners raised policy entropy, which made the samples---and the greedy rollout drawn from the same policy---stranger still: mean gains fell from $-14$ ($\best$) and $-15$ ($\spec$) over steps 0--39 to $-35$ and $-45$ over steps 159--198, while the relative margin the run optimized \emph{widened} to $+10$ nats and the eligibility count rose. The policy's cross-entropy on its own imitated thoughts climbed from 88 to 120 nats, and thought content decohered from fluent, topical text at step 0 to agglutinated noise by step 175 (\texttt{iterateagrowanomelisuntvinill...}). The base model was untouched throughout (the gate stayed near-closed), making the failure invisible to every loss curve except the gain trajectory itself. The absolute condition $\gain(\best) > 0$ closes the exploit by construction: noise can never beat silence. \emph{Lesson: a baseline must be a floor, not only a rival---each half of the eligibility test guards a direction the other cannot.}

\paragraph{The reader manufactures value for the writer's habits (run 10b$'$).} The absolute bar and a context floor were added mid-run, resuming from a checkpoint that had already imitated ${\sim}25$ noise thoughts. Two dozen steps later the failure returned \emph{through the reader}. The reader trains by backpropagation on every sampled thought---that is how it learns to read---so it co-adapts to whatever the writer habitually emits. The contaminated policy's capital-letter register became a recognizable shape, and the reader learned a use for it: mean gains rose from $-14$ to $-2.7$, the \emph{greedy} rollout's gain went positive, and caps noise began clearing the $+2$ bar at legitimate anchors ($+2.3$ to $+4.4$ nats), with margins over the guess sitting at the selection-noise floor. The two halves of one network were converging on a content-free private protocol. No threshold on $\gain$ can exclude this, because the value is real---it is just not \emph{about} anything. The shuffle self-control (Appendix~\ref{sec:distill}) is the structural fix: a shuffled thought keeps the register and loses only the meaning, so protocol value passes the shuffle and is rejected, while informational value does not and survives. The restart also returns to the clean rung: a contaminated policy cannot be fenced after the fact. \emph{Lessons: the reader is a trainable judge and will drift toward the evidence it is given; and contamination is grounds for a clean restart, not for more rules.}

\paragraph{The register exploit survives a relative shuffle control (run 11).} The shuffle self-control was implemented as a \emph{margin}: the winner must beat its own shuffled copy by $\delta = 1$ nat. Run 11 (the $m{=}4$ tournament from the 1169M rung) showed the flaw: its rising pass rate was carried by capital-letter agglutinations whose shuffled copies scored \emph{positive} ($+1$ to $+3.5$ nats)---the reader had once more learned a value floor for the register itself, and a floor plus a sliver of order-value clears any fixed margin. (We tested and rejected the interesting alternative that the caps strings were an acronym code: their window-initial-letter match rate equaled shuffled chance.) The fix is absolute, not relative: a \emph{register floor} declares a winner ineligible unless its shuffled copy scores below $+0.5$ nats---order-destroyed content must be near-worthless. Every genuine content pass ever recorded in the project shuffles to $\le -0.8$; every register pass fails the floor. \emph{Lesson: pair each relative gate with an absolute one (the second instance of this principle), and treat any positive score for destroyed content as disqualifying, not merely discounting.}

\paragraph{With every exploit closed, nothing passes: the bootstrap fails at maturity (run 12).} Run 12 ran the full gate stack---absolute bar, winner's-curse-calibrated thresholds, shuffle margin, register floor---from a 2.07B-token base (held-out mixture CE $3.002$). Over 973 steps and 19{,}182 scored thoughts, 34 passed: $0.177\%$, which is \emph{exactly} the false-positive tail the max-of-4 calibration predicts, flat from step 100 to step 973. The thoughts themselves never left rare-token multilingual salad, and the mechanism is a closed loop: no pass $\Rightarrow$ no writer gradient $\Rightarrow$ the thought policy remains the base LM's tail distribution under exploration temperature $\Rightarrow$ no pass. The mature reader makes the loop tighter, not looser---its silence baseline is strong enough that the best of four sampled thoughts \emph{hurt} the window by $3.5$ nats on average---while the same reader still converts oracle thoughts into $+28$ to $+80$ nats. The asymmetry is the diagnosis: reading capacity is present and grows with maturity; \emph{writing} cannot be bootstrapped by rejection-sampling alone from a policy whose base rate of useful thoughts is zero. \emph{Lesson: gates select, they do not teach. A selection mechanism with nothing to select is not a slow learner, it is a fixed point---the writer needs a dense supervised signal before selection has anything to amplify.}

\subsubsection{The long-horizon free-form run}
\label{sec:think10}

Run 10c instantiates the full method of Section~\ref{sec:method} at the 870M-token rung: $L = 24$, $k = 64$, $\gamma = 0.97$ (effective horizon $28.6$), $m = 2$ sampled rollouts plus the greedy speculation rollout, the four-way eligibility of Eq.~\eqref{eq:elig} ($\varepsilon = 1$, $A = 2$, $\delta = 1$, $F = 6$), the 128-token context floor on anchors, distillation weight $0.15$, $\alpha = 0$ (no policy gradient), free-form generation (no allowlist, top-$512$, $\tau_2 = 1.4$), probes at $10\%/10\%$, learning rate $5{\cdot}10^{-5}$; $32{,}768$ visible tokens per step; 3000 steps planned. This configuration was reached in four same-day iterations, each terminated by a targeted measurement rather than a loss curve: no absolute condition $\to$ the noise-distillation loop; bar at exactly $0$ $\to$ blind-baseline anchors and selection noise; a resume from a contaminated checkpoint $\to$ reader--writer co-adaptation on a content-free register (Appendix~\ref{sec:failures}; Appendix~\ref{app:history}, rows 10a--10c). The current run starts from the clean rung. Every thought that passes Eq.~\eqref{eq:elig} is recorded verbatim with its gain, guess, and shuffle scores.

The aborted attempt already established three properties of the setup that carry over unchanged, since they concern the base model and the probes rather than the learned policy:
\begin{itemize}
    \item \textbf{The base model is protected.} Pass-1 NTP cross-entropy holds at its starting level under thinking training (drift ${<}0.1$ nats against a kill threshold of $+0.5$): the near-closed gate and the honesty rail keep the language model intact even while the writer misbehaves.
    \item \textbf{The ceiling is open.} Oracle probes gain $+32$ to $+47$ nats per discounted window at these anchors---perfect information about the future is worth a great deal, so there is ample headroom for learned thoughts.
    \item \textbf{The 870M base writes fluently.} Free-form thoughts at step 0 are qualitatively different from run 9's fragments: context on Brownian-motion particle sizing produced \texttt{``on The Standardized Chemistry Experiment Curding with Brownian Systems. More >> Nanodextrous Chlorimeters Are''}---confabulated, but fluent, topical, and sentence-shaped. Under the absolute eligibility gate, this base fluency is the resting state of the writer: the policy does not move until a thought genuinely beats both silence and the model's own guess.
\end{itemize}

Under the corrected eligibility, the primary observables are the eligibility count (expected near zero at first, by design; its rise is the signal that genuinely useful thoughts exist and are being amplified), the $g_B - g_S$ margin \emph{conditional on} $g_B > 0$, the gate's $w_{\mathrm{or}}/w_{\mathrm{ng}}$ separation, and the thought dumps. The run was stopped deliberately at step 1447 of 3000 (${\sim}47$M visible tokens) once the pass-rate verdict below was statistically unambiguous; the compute moved to the token-matched comparison and the follow-up run.

\paragraph{First content-verified thoughts.} Within the first 169 steps, six thoughts passed all four conditions of Eq.~\eqref{eq:elig}, against ${\sim}30$ sampled thoughts per step---the gate operates as a rare-event detector. Each pass is audited by construction. An early example, at an anchor 463 tokens deep in a passage on soil science:
\begin{quote}\small
\textbf{thought:} \texttt{dubeussing disease -- accretition of bulk )\;/\;Dust-stressed agricultural tillage soil was less resistant to} \\
\textbf{scores:} gain $+2.62$ nats over silence; the model's own greedy guess scored $-4.34$; the same thought with its tokens shuffled scored $-7.95$.
\end{quote}
The ordered thought helps; the identical multiset of tokens in random order hurts by $8$ nats---a $10.6$-nat swing attributable purely to token order. Under the analysis of Appendix~\ref{sec:distill}, this is value carried by content, not register: the first thoughts in this project, across ten runs, whose measured usefulness provably derives from what they say. Their content is imperfectly fluent but recognizably \emph{anticipatory}---guesses at where the passage is heading.

\paragraph{The full run (steps 0--1447): existence proven, amplification failed.} Thirty-nine thoughts passed all four conditions, out of ${\sim}43{,}000$ sampled candidates---and the pass rate \emph{declined}: ${\sim}4.3$ per 100 steps over the first half, ${\sim}2$ per 100 after step 800, and zero in the final ${\sim}300$ steps (probability ${\approx}0.2\%$ under the run-average rate; a real decline, not noise). The passes themselves are healthy: topically diverse, never shallow (every anchor ${\ge}165$ tokens into its context, median depth 499---the context floor left no loophole), mean gain $+3.5$ nats in the first half and $+4.0$ in the second, mean order-swing $+18$ nats between each winner and its shuffled copy. The largest (step 836, $+11.1$ nats, 713 tokens deep in a JavaScript-DOM tutorial) is a rough natural-language gloss of what the surrounding code is doing (\texttt{``just now have created a table titled string from\ldots''}); the model's own greedy guess scored $+5.3$, the shuffled copy $-5.9$. The health rails stayed green throughout: pass-1 NTP flat ($3.31 \to 3.33$ against a kill threshold of $+0.5$), oracle ceiling $+54$ nats mean whenever probed, and none of the failure signatures of runs 8--10b$'$ reappeared---the four-way gate held for 1447 steps.

Why the decline? \textbf{The bar is a moving target.} Every training step, the second gradient on reward windows makes the model's own greedy guess better; the writer, meanwhile, received exactly 39 distillation gradients all run---one per ${\sim}750$ candidates at $m = 2$. The model out-improved its own thoughts: mean sampled gains drifted from $-8$ to $-20$ nats and the gate correctly priced the average thought down to $w \approx 0.03$. The gate works as a rare-event detector; the amplification loop it feeds starves. After ten runs, the binding constraint is no longer the \emph{existence} of verified-useful thoughts (solved, and audited per-instance) but the \emph{throughput} of them---more rollouts per anchor is the principled lever, and it is affordable only after the engineering of Appendix row S1.

\subsubsection{Runs 11--12: the register closed, then the maturity null result}
\label{sec:run1112}

Run 11 answered 10c's throughput question in the worst way available: at $m{=}4$ rollouts and ${\sim}6\times$ the step rate, the pass rate finally \emph{rose} ($1 \to 11$ per 100 steps over 600 steps)---and the passes were generation three of the register exploit (Appendix~\ref{sec:failures}), caught by the per-pass audit trail rather than by any curve. Three runs, three maturities (870M, 1169M, 2070M), one monotone pattern: the reader's ceiling rises with maturity, the honest sampled pass rate falls toward zero, and the free-form RL bootstrap has no purchase anywhere on the curve.

\subsection{Run 13: dense parallel thoughts with an oracle-seeded writer}
\label{sec:densepar}

The redesign keeps the question (can thought content earn its keep under a next-token objective?) and replaces the learning mechanism that runs 10--12 falsified. Stated plainly, the current experiment teaches three separable skills and measures each one directly: \emph{writing} (produce a short thought that anticipates the text, learned first by imitating the true continuation beyond the reward window, then refined by reinforcement on measured gain); \emph{reading} (turn a visible thought into better next-token predictions, trained on known-good thoughts before being asked to price the model's own); and \emph{deciding} (when to open a thought, and how long to keep it, both ordinary token actions with prices attached). Four changes implement this, each forced by a measured failure:

\paragraph{Dense parallel anchors.} Thoughts are generated at \emph{every} stride-8 position ($N{=}118$ anchors per 1024-token sequence; windows of $k{=}8$ tile the sequence), in the spirit of Quiet-STaR's parallel generation \citep{zelikman2024quietstar}. One spliced buffer holds the clean sequence, all thought blocks, and per-anchor window copies; because anchors are at fixed stride, every attention mask and position tensor is a per-run constant compiled once. The mask enforces \emph{zero cross-anchor visibility}: each window row reads the clean prefix (not other windows) plus its own thought, so gains are exact per-anchor counterfactuals against the silence baseline computed by the same forward pass---no contamination, no frozen referee model. Generation becomes $L{=}12$ dense $[2 \times 118]$ decode launches per micro-batch instead of run 12's serial tiny-batch loop: ${\sim}2$--$4\times$ vanilla cost against run 12's measured $16\times$, at roughly $250\times$ the gradient signal per hour.

\paragraph{An oracle-imitation channel for the writer.} Run 12's diagnosis was a writer with no gradient. Run 13 gives it one from step 0: with probability $p_{\mathrm{or}}$ (starting $0.9$, decaying to $0.2$), a micro-batch is an \emph{oracle micro}: the thought content at every anchor is drawn from the real tokens \emph{beyond} the scored window ($x_{n+k+1..}$---disjoint from every window by construction, so nothing leaks), the reader trains to use it, and the writer trains to \emph{imitate} it. Writer imitation of this target is long-horizon prediction of the model's own future text---a legitimate, dense, well-posed LM objective, not imitation of the policy's own habits (the run-8 collapse was self-imitation; this is supervised by reality). Sampled micros interleave from the start and take over as $p_{\mathrm{or}}$ decays: thoughts are then the writer's own guesses about where the text is heading, scored counterfactually, with reader training gated by the full audit stack (absolute bar, shuffle margin, register floor---the shuffled copy is scored alongside \emph{every} sampled micro, no lazy path) and REINFORCE applied with a whitened, clipped advantage against the greedy-speculation baseline, ramping in only after the imitation warm-up.

\paragraph{The learnable think-gate: \emph{when} to think is the model's action.} Runs 7--12 placed thoughts by our heuristics (an entropy trigger, then a fixed grid). Run 13 makes the trigger itself learned: the emission probability of \tstart{} at each anchor row---an ordinary next-token probability, computed from clean context by the same softmax as every real token---\emph{is} the think-gate, a learned function of context strictly richer than any scalar threshold. Training samples the decision with an exploration floor, $q_a = \varepsilon_t + (1-\varepsilon_t)\min(1, p(\tstart)_a/\theta)$ ($\varepsilon_t: 0.5 \to 0.05$; $\theta = 10^{-3}$, deliberately permissive), and credits the \tstart{} logit by REINFORCE with the thought's \emph{absolute} net value:
\[ R^{\mathrm{gate}}_a \;=\; \gain_a \;-\; \lambda_{\mathrm{len}}\,\mathrm{len}_a \;-\; c_0 \;-\; \lambda_{\mathrm{rate}}\cdot\#\{\text{active thoughts in the preceding 8 anchors}\}, \]
with $c_0{=}0.5$ nats the price of opening a thought at all and $\lambda_{\mathrm{rate}}{=}0.25$ the crowding tax that discounts many thoughts in a short span---thinking is a budgeted resource, and bursts must out-earn their density. The absolute (unwhitened) credit matters: the gate's question is ``was this thought worth having?'', not ``was it better than its peers?''. Because the gate rides the ordinary \tstart{} logit, the end state is native: a model that, while generating, emits \tstart{} exactly where thinking pays, thinks for as long as it pays (next paragraph), and closes with \tend. The physical stride-8 slots remain only as pre-compiled capacity; a slot the gate declines carries an empty \tstart\tend{} block and zero loss. Oracle micros teach content at coin-flip slots, never through the learned gate, so oracle-inflated gains cannot teach the model to think everywhere.

\paragraph{Compression thoughts: model-controlled length with a price per token.} Thoughts have no fixed length. The stop token \tend{} is an ordinary action of the writer (legal after a 2-token minimum, up to $L_{\max}{=}12$); once emitted, the slot pads and the thought's \emph{length} is its content-token count. Two mechanisms make length meaningful rather than merely permitted. First, the imitation targets are \emph{length-jittered}: each oracle target is the true continuation truncated at $\ell \sim U\{3..L_{\max}{-}1\}$ with \tend{} appended, so the stop action is taught (and its logit calibrated) from step 0, and the reader learns from the start that thoughts come in varying lengths with padding to ignore. Second, the REINFORCE reward is $\gain - \lambda\,\mathrm{len}$ ($\lambda{=}0.15$ nats/token), with the greedy baseline paying for its own length symmetrically---so a thought keeps a token only if that token buys more than $\lambda$ nats of predictive gain. This is a compression objective: the optimum is not the future verbatim (that costs $\lambda$ per token parroted) but the \emph{shortest string that recovers the gain}---pressure toward abstraction (``a proof by contradiction; conclusion coming'') rather than continuation. The mean thought length is itself a primary observable: under the length price, whatever length survives is the model's own estimate of how much thinking the context deserves.

\paragraph{One graph.} All three losses---clean NTP on every real token (the vanilla objective, unchanged), gated window CE (the reader), and the writer loss (imitation CE and REINFORCE are the \emph{same} weighted cross-entropy on thought rows, since a teacher-forced thought's log-probability is its negated CE; the advantage rides the per-row weights)---are three weighted sums over one forward pass, with all weights and norms as host-set tensor inputs. The implementation is gated by a CPU equivalence suite in the run-10c style: mask-level no-leak assertions, KV-cached parallel decode vs.\ naive per-anchor forwards ($4{\cdot}10^{-7}$ worst logit error on a 3-layer probe, $4{\cdot}10^{-6}$ at full 0.6B geometry), scoring vs.\ naive spliced forwards, and token-exact top-$K$ sampling.

The run trained from the 2.07B base; Appendix~\ref{sec:run13obs} reports what it did. Its success criteria were registered in this order: imitation CE falling (the writer learns the long-horizon skill); oracle gain rising (the reader learns to consume thoughts); sampled-thought mean gain climbing toward and past zero (the handover); and an eligible rate that a dense denominator finally makes statistically meaningful ($\sim$$950$ audited candidates per step vs.\ run 12's $\sim$$20$). Failure of the first two criteria would be a capability statement about 0.6B models; failure of only the last would locate the gap between imitating foresight and \emph{having} it---either way the dumps, recorded verbatim per pass as always, would say which.

\paragraph{The warm-up did what it was designed to do (Fig.~\ref{fig:think13}a,b).} Imitation CE fell $5.9 \to 3.7$: the writer learns long-horizon prediction as an ordinary supervised skill. The reader's oracle gain rose from $-3.4$ through zero to $+1.5$ nats. We stress what this number now means: unlike the $+28$--$80$ nat ``oracle ceilings'' of runs 7--12, which teacher-forced the \emph{literal window} into the thought (an upper bound built on a leak), the run-13 oracle is text from \emph{beyond} the scored window---a genuine hint. An untrained reader gains nothing from it (the $-3.4$ start); a reader that has learned to consume hints converts it into $+1.5$ nats of discounted window likelihood. To our knowledge this is the first leak-free demonstration in this project that the reading skill is trainable at all.

\paragraph{An engineering interlude with a scientific moral.} For its first 310 steps the run's \emph{sampled} thoughts appeared to be rare-token salad pinned at the full 12-token budget, while the training curves above improved steadily. The contradiction was resolved by replaying one training step on CPU with identical weights and RNG stream: the true policy was producing coherent, self-terminating thoughts---the device sampling path was returning garbage, because the Neuron compiler miscompiles (or crashes on) top-$k$ over the 152k vocabulary at every shape we tested, and had been silently corrupting the logit candidates it did compile. The corrupted channel fed only the (weight-zero, pre-handover) rollout path; every gradient flowed through separately verified graphs, so the run resumed from its checkpoint with the top-$k$ moved off-device and nothing lost but wall-clock. The moral, twice paid for in this project (fractional positions; this): \emph{on an accelerator, equivalence tests that pass on CPU certify the semantics, not the compiled artifact}---the decisive audit is an on-device replay against ground truth. It also retroactively softens one run-12 observation: its sampled thoughts traversed the same broken path, so their salad appearance was partly transport corruption (the run's null \emph{conclusion} stands: pass rates were measured by the verified scoring graph).

\paragraph{With the sampler fixed, the model's own thoughts became legible immediately (Fig.~\ref{fig:think13}c,d).} Mean sampled gain jumped from $-3$ to $-0.6$ and crossed zero after the handover; the fraction of positive-gain thoughts rose from $4\%$ to ${\sim}60\%$; the eligible rate reached $0.010$ ($5\times$ the run-12 noise floor) \emph{before} reinforcement contributed; and mean thought length dropped from the pinned $12$ to ${\sim}6.5$ tokens, chosen by the model's own \tend. The thoughts read as short anticipations. Three verbatim examples (context $\to$ thought, each self-terminated):
\begin{quote}\small
\emph{home-inspection Q\&A list, ``\ldots outlet a safety defect?\ $\bullet$ When was''} $\to$ \texttt{?\;$\bullet$ How is it \tend} \quad (gain $+1.5$: it recognizes the format and drafts the next question)\\
\emph{physics-code tutorial, ``\ldots new physical properties need to be''} $\to$ \texttt{are inside the input of the function calculations. This time \tend} \quad ($+2.1$)\\
\emph{5G article} $\to$ \texttt{of data\;\textbackslash n\;Not only are 5G data \tend} \quad ($+2.3$, shuffled copy $+0.1$)
\end{quote}

\paragraph{The handover immediately re-taught two old lessons, live.} Within 60 steps of reinforcement switching on (at $0.2$ of full strength): (i) \emph{register inflation returned}---mean gains went positive, but the gains of \emph{shuffled} copies tracked them almost exactly, the signature of the reader manufacturing order-free value (run 10b$'$/11's pattern, now caught in real time by the always-on audit rather than post-hoc); and (ii) \emph{the shared trunk paid for the policy gradients}---clean NTP drifted $+0.49$ nats, a hair from the runaway guard's kill line, driven by the unlikelihood half of REINFORCE (negative-advantage ascent on thought rows) leaking into the language model. We stopped the run one strike before the guard would have, and resumed from the pre-handover checkpoint with three changes that are each the established design principle applied one level up: the reinforcement reward (content \emph{and} gate) is now the \emph{shuffle-corrected} gain $\gain - \gain_{\mathrm{shuf}}$---the minimal-pair difference that pays only for token order, cancelling register value by construction; negative advantages are damped $4\times$ (reinforce what works, only gently punish what does not); and the ramp is $3\times$ slower at $0.3\times$ the weight. The gate meanwhile behaved exactly as priced: with average net thought value below its opening cost, it cut $p(\tstart)$ by four orders of magnitude within 30 steps---``think much less'' is the correct first policy, and whether it re-opens selectively where thoughts pay became the question the corrected run answered.

\paragraph{Run 13$'$: the honest reward converges to silence (Fig.~\ref{fig:think13collapse}).} The corrected run trained 774 further steps before the runaway guard killed it at step 1174. Every component behaved lawfully; the collective outcome is the third falsification. (ii)~Faced with a reward of zero minus prices, the writer minimized the prices: mean length fell from $6.5$ to $2.3$ tokens (the floor is 2), and the greedy mode collapsed to a single universal thought (\texttt{1)}\tend---the run-8 failure family, rediscovered by gradient descent as the cheapest legal act). (iii)~The gate solved its pricing problem \emph{correctly}: with net thought value strictly below the opening cost, REINFORCE drove $p(\tstart)$ through twenty orders of magnitude toward never-think, leaving the realized think-rate pinned to the exploration floor. (iv)~The trunk still paid: clean NTP drifted from $2.94$ to $3.34$ over the reinforcement phase---noise-mean-zero policy gradients through a shared backbone are not free even when damped---crossing the $+0.5$ guard, which ended the run. Held-out CE tells the same story from outside: $3.002$ for the vanilla baseline, $3.050$ at the pre-handover checkpoint (a ${\sim}0.05$-nat multi-task tax, uniform across domains), and $3.255$ by the last saved reinforcement-phase checkpoint (step 1100)---the supervised warm-up cost a twentieth of a nat, and reinforcement then spent a further fifth of a nat buying nothing.

\paragraph{The asymmetry, now sharp.} Three mechanically independent reinforcement schemes have now been run to completion at this scale: rejection-sampling self-amplification (run 12: statistically zero signal), REINFORCE on raw counterfactual gain (run 13 handover: register exploit within 60 steps), and REINFORCE on the minimal-pair-corrected gain (run 13$'$: lawful convergence to silence). Against them, the two \emph{supervised} channels never stopped working: imitation CE fell whenever the oracle mix was high, and the leak-free oracle gain rose monotonically from $0.1$ to $1.9$ nats---through the entire collapse (panel~d). The picture this selects is not ``reinforcement was configured wrong'' but an information-theoretic asymmetry: the reader can convert \emph{genuine} information about the future into likelihood, and the writer can learn to \emph{approximate} that information under supervision, but the policy's own samples at this maturity contain no order-borne information for the reader to buy---so any honest reward on sampled thoughts has silence as its optimum, and the optimizer, given an exploit-free objective for the first time, simply found it. The binding constraint is the sample quality of the base policy, not the learning mechanism.

\paragraph{Run 14 (anchored), first 2{,}500 steps: stability delivered; a tail, not yet a mean.} The anchored design (no handover; Appendix row 14) trained ${\sim}2{,}500$ steps ($82$M thinking-mode tokens) and its structural claim holds: \emph{nothing has collapsed}. Thought lengths sit at $5.9$ tokens and have been flat for two thousand steps (13$'$ was at the 2-token floor by this point); imitation CE holds at $3.4$--$3.8$; thoughts remain readable anticipations; clean-NTP drift is bounded and oscillating around $+0.3$ rather than escalating through the old kill line; and the leak-free oracle gain has kept climbing to $+1.6$ nats. On the decisive metric the verdict so far repeats 13$'$: raw sampled gain again crossed zero (to $+0.3$) with the shuffled-copy gain tracking it, so the \emph{mean} order-borne value remains zero ($|g - g_{\mathrm{shuf}}| < 0.04$ throughout). But one quantity has, for the first time in this project, trended in the bootstrap's favor: the \emph{eligible rate}---the per-anchor frequency of sampled thoughts that individually clear the full audit (absolute gain, shuffle margin $>1$, register floor)---has tripled, $0.007 \to 0.025$, now $12\times$ the run-12 noise floor and $2.5\times$ anything 13$'$ reached. The mean says the typical thought still carries no order-borne information; the tail says thoughts that do are becoming steadily less rare while the anchor keeps the policy from collapsing onto either extreme. Whether that tail can be fattened---by wider exploration, longer horizons, and a more mature base (Appendix~\ref{sec:scaled})---is exactly the scaled experiment's question. The gate, meanwhile, remains closed ($p(\tstart)$ at numerical zero, the exploration floor doing all sampling): correct pricing while the mean is zero, and the reason the floor is permanent.

\paragraph{The 9B base and the first \emph{pre-training} bootstrap-viability probe (run 15).} The scaled experiment of Appendix~\ref{sec:scaled} moved the programme to a new platform. The platform is a trn2.48xlarge (16 Trainium2 devices, $64$ logical NeuronCores, $1.5$\,TB of accelerator memory, $16\times$ the cores of the node that produced every result above), and the base is a vanilla checkpoint trained to \textbf{8.99B tokens} ($3.01$B on the original mixture, then $5.98$B fresh tokens of a disjointly-drawn 9B corpus)---$4.3\times$ the maturity of the 2.07B base against which all three falsifications were measured. Its held-out mixture CE is $\mathbf{2.775}$ (32 sequences, the standard ruler), against $3.002$ for the 2.07B base.\footnote{Two provenance caveats, both measured by document-level hashing rather than assumed. The 3B and 9B corpora are drawn from the same upstream files and share $5.1\%$ of their documents, so the ``fresh'' continuation is $95\%$ fresh, not disjoint; and $2.97\%$ of held-out validation documents ($716/24{,}136$) also occur in training, so absolute CE values carry a small optimistic bias. Both affect the 2.07B and 8.99B numbers through the same ruler, so the comparison stands.}

Before any thinking training, we ran the two probes Appendix~\ref{sec:scaled} prescribes---as a zero-update pass ($\mathrm{lr}=0$) of the full audited scoring stack over $9{,}635$ anchors---which for the first time measures bootstrap viability on a base that has \emph{never seen} the thinking format:

\paragraph{Run 15: the anchored recipe at 8.99B tokens, and a fourth falsification.} We then ran the run-14 recipe unchanged from the 8.99B base on all $64$ cores (global batch $128$ sequences), for $3{,}899$ steps ($511$M thinking-mode tokens); run 14's reported horizon of $2{,}500$ steps falls inside this, so the comparison is direct. \emph{Structurally the design holds completely.} Nothing collapsed: thought lengths settled at ${\sim}6.1$ tokens and stayed there (run 13$'$ was pinned at its 2-token floor by step 1{,}174), imitation CE fell $4.04 \to 2.6$, thoughts remained fluent and self-terminating, and reinforcement sat at its full $0.15$ weight for ${\sim}1{,}900$ steps with a bounded trunk---the erosion that killed 13$'$ never began. \emph{Scientifically the result is the cleanest negative the project has produced.} Pooling every sampled step after the metrics plateau (step ${\ge}800$; $2{,}293$ steps, $53{,}529$ audited anchors):
\begin{equation*}
\gain - \gain_{\mathrm{shuf}} \;=\; -0.0673 \pm 0.0037, \qquad \text{eligible rate} \;=\; 395/53{,}529 \;=\; 0.0074 .
\end{equation*}
Eighteen standard errors below zero. Every previous statement in this paper about order-borne value was ``indistinguishable from zero''; this one is a measurement, and its sign is negative.

Two things make this more informative than a repetition of runs 13$'$/14. First, \textbf{the eligible rate did not fatten}. Run 14's one encouraging signal was a tripling, $0.007 \to 0.025$, over exactly this many steps; run 15's rate oscillates in $[0.002, 0.012]$ with no trend, from a base $4.3\times$ more mature. The quantity the scaled experiment was built to test came back flat. Second, and more sharply, \textbf{reader capacity and writer bootstrap are dissociated}. The leak-free oracle gain crossed zero near step $1{,}350$ and reached $+0.13$---the reader demonstrably learned to convert genuine information about the future into window likelihood---while $\gain - \gain_{\mathrm{shuf}}$ over the same interval went $-0.029 \to -0.080 \to -0.095 \to -0.067$, i.e.\ did not move. The implicit hope of the anchored design was a chain: imitation trains the writer, the reader learns to read, and once the reader can \emph{pay}, sampled thoughts begin to earn and the gate re-opens. \textbf{The third link is now directly falsified with a tight error bar}: a reader that provably profits from real future information still finds nothing to buy in what the policy samples.

\paragraph{What the audited tail actually contains.} The negative mean is not the whole story, and the distinction matters for what to do next. Of $53{,}529$ audited anchors, $395$ ($0.74\%$) passed the full eligibility stack of Eq.~\eqref{eq:elig}; those $474$ dumped passes carry a mean order-borne value of $\mathbf{+1.73}$ nats (median $+1.49$). So the mechanism \emph{works where it fires}: when a sampled thought is genuinely informative, the minimal-pair audit detects it and prices it correctly, at well over a nat. The failure is entirely one of \emph{rate}---the other $99.26\%$ of thoughts are worth slightly less than their own shuffles, and they set the mean. This reframes the negative result usefully: the constraint is not that order-borne value is undetectable or unrewardable at this scale, but that the policy proposes it too rarely for the mean---and therefore the gate---ever to go positive. The two remedies that follow are widening the search (more rollouts per anchor) and lengthening the horizon so that a larger fraction of proposals can pay, which is the subject of Appendix~\ref{sec:scaled} step 4 and of run 16 below.

The held-out ledger records the price of this: $2.7749$ (base), $2.8074$ (step 200), $2.8188$ (600), $2.8585$ (1{,}200), $2.9030$ (2{,}500)---a tax of $+0.128$ nats accumulating at a steady ${\sim}0.04$ per thousand steps. Unlike 13$'$ this is not reinforcement eating the backbone (the trunk is flat across the entire $\mathrm{rl}_w$ ramp); it is the ordinary multi-task cost of training a thinking head that earns nothing. Finally, the \emph{direction} of the policy's drift is itself evidence. The base-policy probe at step 0 produced thoughts like the \texttt{Communication Research 54(1)} citation above, order-borne $+3.85$; by step $2{,}500$ the dumps are uniformly fluent, high-register continuations worth $\pm 0.2$ once shuffled (``\texttt{ as a political figure, much more so than he \tend}''). Training made the policy \emph{more fluent and less order-bearing}---it moved toward the shuffle-proof paraphrase that an $8$-token window is precisely what pays for. We read this as the strongest available argument for the $k{=}64$ horizon of Section~\ref{sec:gain}: abstraction cannot out-earn paraphrase while the reward window is shorter than the paraphrase.

\paragraph{Run 16: the horizon change, and what it cost.}
\label{sec:run16}
Run 16 applies both untried levers from Appendix~\ref{sec:scaled} at once, from the same $8.99$B vanilla base: the horizon ($k{=}8 \to 64$) and the search width ($R{=}1 \to 8$ with the paired baselines of Section~\ref{sec:rollouts}). They fund each other in the sampler's $[R{+}1,N,V]$ transfer budget---$k{=}64$ drops anchors per sequence $118 \to 14$, so $R{=}8$ costs $126$ decode rows against the $236$ runs 13--15 already paid---though they compound in host memory, which is why the run uses $32$ ranks with $\mathrm{grad\_accum}{=}4$, preserving run 15's exact $131{,}072$ tokens per step.

The horizon change does what it was designed to do at the level of individual thoughts. Eligible thoughts now anticipate structure tens of tokens ahead, which a $k{=}8$ window could not even score: given a worked coordinate-geometry example ending ``\texttt{Take \$\$(1)}'', the model writes \texttt{x + 3\$\$)\$\$$\backslash$left(} against a true continuation containing $2x+3y-4=0$ (order-borne $+3.74$, its shuffle $-3.20$); given a reference to a trial ``\texttt{\ldots from SIOPE}'' it writes \texttt{7.}, anticipating a numeric suffix where the truth is \texttt{L-6} (order-borne $+5.25$).

But the aggregate is worse than $k{=}8$ on every supervised channel, though the imitation gap is modest ($+0.38$ nats) and the reader gap is not:

Two negatives follow, and they are informative in different ways. First, \textbf{density was not the binding constraint}: installing the soft gate of Eq.~\eqref{eq:softelig} moved the distillation mass from \emph{exactly zero} to a dense weighting, and over the next $300$ steps $\gain - \gain_{\mathrm{shuf}}$ stayed flat at $-0.18$ with the gap between $\gain$ and $\gain_{\mathrm{shuf}}$ not widening. \paragraph{Run 17: the horizon curriculum, and an invariant.}
\label{sec:run17}
Run 16's diagnosis---that at a $28.6$-token horizon the reader never learns a thought is worth reading---selects a curriculum rather than another geometry. Since $\gamma$ sets the \emph{effective} horizon independently of $k$, we anneal $\gamma: 0.85 \to 0.97$ (horizon $6.7 \to 28.6$ tokens) over steps $200$--$2500$, starting at almost exactly run 15's $k{=}8$ horizon of $7.2$, where the reader demonstrably does learn, and ending at the long horizon that makes paraphrase unprofitable. The geometry stays $k{=}64$, so no graph is recompiled. Run 17 starts fresh from the $8.99$B vanilla base: resuming run 16 would confound whether the curriculum \emph{works} with whether it can \emph{undo} a policy already trained to ignore thoughts.

The curriculum does what it was designed to do for the reader. Insertion damage at launch is $3$--$5\times$ smaller ($\gain = -3.4$ against run 16's $-17.8$; $\mathrm{orG} = -3.1$ against $-9.3$), and $\mathrm{orG}$ climbs past run 16's permanent $-1.45$ ceiling by step $200$, reaching $-0.49$. Imitation CE falls $6.3 \to 4.0$ and lengths leave the $12$-token budget of their own accord, settling near $6.9$.

The order-borne value does not follow, and the way it fails is the most informative result in this paper. Pooling all sampled steps after the metrics settle (step ${\ge}400$, $n{=}249$): $\gain - \gain_{\mathrm{shuf}} = -0.070 \pm 0.008$. Set beside the two runs that precede it:

Runs 15 and 17 differ in horizon by $8\times$, in search width by $8\times$, and in gate density by more than an order of magnitude, and they agree on the order-borne value to within one standard error. Run 16's $-0.18$ is the outlier, and it is explained: its reader was broken, so \emph{nothing}---not the thought, not its shuffle---was legible. \textbf{Where the reader works at all, the order-borne value of the policy's own thoughts is a small negative constant.} It is an attractor, not a coincidence of one configuration.

The mechanism is visible in the trajectories rather than the endpoints. In every run $\gain$ rises and $\gain_{\mathrm{shuf}}$ rises beneath it in lockstep, so that $|\gain - \gain_{\mathrm{shuf}}|$ \emph{contracts} toward zero---run 16 went $0.77 \to 0.04$, run 17 $-0.23 \to -0.06$. A model learning to \emph{use} thoughts would separate these curves. These models are learning to make thoughts \emph{harmless}: to tolerate the insertion rather than profit from it, which is the cheapest way to stop being penalised for it. That is a failure no counterfactual reward can price, because a harmless thought and a useful one differ only in a quantity the model can drive to zero from either side.

We stress what this does \emph{not} say. Individual thoughts continue to clear the audit with real margins---run 16's eligible set anticipates structure tens of tokens ahead at order-borne $+2.5$ to $+5.3$, and run 15's $395$ passes average $+1.73$ nats. The tail is genuine and it is legible. What four configurations now agree on is that the tail cannot be widened into a mean by any of the levers we have: not maturity ($2.07 \to 8.99$B), not horizon ($k{=}8 \to 64$), not search width ($R{=}1 \to 8$), not reward density (a gate that fired on nothing made dense), and not a curriculum that repairs the reader.

\paragraph{The falsification criteria as they evolved.} The run fails if any of the following holds: eligibility never rises from zero (no sampled thought ever beats both silence and the model's own guess); the gate never separates $w_{\mathrm{or}}$ from $w_{\mathrm{ng}}$; or the thinking checkpoint loses to its token-matched vanilla twin on both evaluation modes. Scored against run 10c: none of the three held---eligibility rose from zero (39 audited passes), the gate discriminates, and the checkpoint \emph{beats} its twin on held-out CE. We then wrote: if a 4-rollout tournament at ${\sim}6\times$ the step rate still cannot lift the pass rate, the self-amplification story at this scale is wrong and we will say so. Runs 11 and 12 answered, and we say so: run 11's lifted pass rate was an exploit (register generation three), and run 12---every exploit closed, the most mature base available---measured the honest pass rate at the calibrated noise floor. \emph{Rejection-sampling self-amplification of free-form thoughts is falsified at 0.6B scale, at every maturity we tested.} What survives falsification is the substrate: verified content-borne value exists (10c's 39 passes), the reader converts good thoughts into $+28$ to $+80$ nats at every maturity, and thinking training never damaged the base. Run 13 (Appendix~\ref{sec:densepar}) therefore replaces the falsified mechanism, and inherits fresh criteria: it fails if imitation CE does not fall, if oracle gains do not rise under a trained reader, or if sampled-thought gains remain pinned at run-12 levels ($\approx -3.5$ nats) after the imitation warm-up hands over. Run 13 has now answered (Appendix~\ref{sec:run13obs}): the two supervised criteria passed decisively (imitation CE $5.9 \to 3.7$; leak-free oracle gain $-3.4 \to +1.9$), and the third passed \emph{in letter but not in substance}---raw sampled gains climbed from $-3.5$ through zero to $+1$, but the order-borne component never left zero, so the climb was order-free value the corrected reward refuses to pay for. With reinforcement given its first exploit-free objective, the optimum it found was silence. We score this as the third falsification of writer bootstrapping by reinforcement at 0.6B scale, and---because the supervised channels kept working throughout---as positive identification of where the constraint lives: in the information content of the policy's own samples.

\subsection{The scaled experiment as planned before the pilots}
\label{sec:scaled}

This section is reproduced as written after run 14, before runs 15--19; it is the plan the pilots executed and, in part, overturned. The results so far isolate two binding constraints, and neither is the method. The first is \emph{sample quality}: every reinforcement failure traces to a base whose own generations carry no order-borne information, so there is nothing for an honest reward to amplify. The second is \emph{iteration speed}: on the current accelerator the recipe runs at $2$--$4\times$ vanilla cost with hour-scale feedback loops, which forced small reward windows, two rollouts, and one configuration per day. A larger instance relaxes both at once. This section records, concretely, what we would run on it.

\paragraph{Step 1: buy maturity, and measure the curve.} Continue vanilla pretraining of the same 0.6B architecture toward $10$--$50$B tokens, saving rungs every ${\sim}5$B. The move is concrete: a trn2.48xlarge node (an order of magnitude more accelerator cores and host memory than the machine every result above was produced on), starting from a sibling instance's vanilla checkpoint at ${\sim}6$B tokens---already ${\sim}3\times$ the maturity of any base tested so far. The thinking stack transfers directly (the parallel-thought module is deliberately plain PyTorch; the launchers are node-size-agnostic), and the platform's standing rules travel with it: host-side top-$k$, and an on-device replay gate before trusting any newly compiled fast path (Appendix rows S1--S3). At each rung, \emph{before} any training, run the two probes that require none: the leak-free oracle-gain probe (does the reader-capacity curve keep growing with maturity?) and the \emph{bootstrap-viability probe}---sample thoughts from the rung's own policy, score $\gain - \gain_{\mathrm{shuf}}$ under the audit stack, and plot the order-borne value of self-generated thoughts against base maturity. Runs 12--13$'$ measured this quantity at three maturities and found zero at all of them; the scientific question is where (if anywhere) the curve leaves zero, and the probe costs minutes per rung.

\paragraph{Step 2: the anchored recipe at every viable rung.} Run the run-14 design (permanent imitation anchor, small always-on reinforcement, recoverable gate) at each rung where the probes look alive---and at one rung where they do not, as the control. Faster hardware converts the recipe's overhead into breadth: a full 6{,}000-step run compressing to hours means the small set of prices that matter (length cost, opening cost, reinforcement weight) can be swept instead of guessed, which we have never once been able to afford.

\paragraph{Step 3: widen the exploration, since exploration is the point.} If reinforcement's job is to search off-manifold, the current runs gave it a search party of one: two rollouts per anchor, one temperature, no bonus for novelty. With compute: $R{=}4$--$8$ sampled rollouts per anchor with paired-sample baselines \citep{kool2019buy}---each rollout baselines the others, unbiased, and the baseline is free; an entropy bonus (or a temperature schedule) on thought rows so the policy is paid to propose diverse candidates while the counterfactual reward selects among them; and the \emph{oracle-regret} baseline, $\gain(\thought) - \gain(\text{oracle here})$, which normalizes anchor difficulty and gives the gate its proper question (``is there anything worth knowing here?''). None of these change what is rewarded---order-borne, audited gain---only how much of thought-space gets visited per gradient step.

\paragraph{Step 4: lengthen the horizon, because that is where deviation can win.} The current $k{=}8$ scored window was a hardware economy, and it quietly stacks the deck against free-form content: within eight tokens, the best cheap thought is nearly always a paraphrase of those eight tokens---which the imitation channel already provides. Abstraction pays over \emph{long} horizons: ``this is a proof by contradiction'' is worth little for the next clause and a great deal for the next paragraph. The original discounted objective ($k{=}64$, Section~2.3) should return, with window copies replaced by discounted scoring over the long window. If free-form deviation from the literal future ever out-earns imitation, it will be here first; conversely, if reinforcement finds nothing to keep even at $k{=}64$ on a mature base with wide exploration, that is a far stronger negative than anything we have measured.

\paragraph{The decisive controls travel with it.} Three arms keep the scaled result honest. The \emph{compute-matched twin}: a vanilla run given the same extra FLOPs the thinking run spends---the bar thinking must clear is not its token-matched twin but the same compute spent on more plain text. The \emph{pause-token arm} \citep{goyal2024think}: same slots, content-free tokens---separating the value of extra computation from the value of content, the confound flagged since run 10c. And the \emph{pretrained endpoint}: the anchored recipe on public Qwen3-0.6B (36T-token maturity, same architecture)---the far end of the maturity axis at fixed parameter count. If the bootstrap-viability curve is still zero \emph{there}, the honest conclusion is that the missing ingredient is parameters, not tokens, and the next experiment changes model size rather than data.

\paragraph{What success and failure look like.} Success is the phase change we defined but never observed: $\gain - \gain_{\mathrm{shuf}}$ sustained above zero; think-mode beating clean-mode on held-out text; and a measurable, paying drift of thought content away from the literal future. Failure at every rung through the pretrained endpoint, under wide exploration and long horizons, would close the question at this parameter count.

\section{Appendix: superseded designs}
\label{app:superseded}

The three subsections below were the method of runs 7--17 (Appendix~\ref{app:previous}) and are retained because Section~\ref{sec:procedure} is only intelligible as the residue of their failure. Each was correct about the exploit it closed and wrong about what it left open.

\subsection{Eligibility by conjunction (runs 7--17)}
\label{sec:distill-old}
\label{sec:distill}

The writer's learning signal in runs 7--17 is best-of-$m$ self-distillation, hardened by two gates. At each anchor we draw $m$ thoughts $\thought^{(1)},\dots,\thought^{(m)} \sim \policy$ at exploration temperature $\tau_2$, plus one \emph{self-speculation rollout} $\spec$ decoded \emph{greedily} from the same policy. $\spec$ is the model's explicit best guess of what comes next, produced without exploration. All $m{+}1$ rollouts are scored with Eq.~\eqref{eq:gain} in no-grad passes. Let $\best = \arg\max_{i \le m} \gain(\thought^{(i)})$. The anchor is \emph{eligible} for distillation iff
\begin{equation}
    \underbrace{\gain(\best) - \gain(\spec) > \varepsilon}_{\text{beat your own guess}}
    ~\wedge~
    \underbrace{\gain(\best) > A}_{\text{beat silence}}
    ~\wedge~
    \underbrace{\gain(\best) - \gain(\operatorname{shuf}(\best)) > \delta}_{\text{beat your own shuffle}}
    ~\wedge~
    \underbrace{-\log \policy(\best \mid \ctx) > F}_{\text{imitate the unknown}},
    \label{eq:elig}
\end{equation}
with margin $\varepsilon = 1$ nat, floor $F = 6$ nats, and $\operatorname{shuf}(\best)$ a uniformly random permutation of the winning thought's tokens. The absolute bar $A \ge 0$ must be calibrated above the measurement noise of $\gain$: keeping the best of $m$ rollouts inflates the winner's apparent gain by roughly $+1$--$1.5$ nats at $m = 2$ (the max of noisy draws), so a bar at exactly $0$ admits selection noise. We use $A = 2$ and $\delta = 1$.

The shuffle condition is the \emph{content self-control}, and it exists because the other conditions all compare the thought against alternatives that differ from it in every respect at once. A shuffled copy of the winner differs in exactly one respect: token order. It preserves the thought's length, vocabulary, and typographic register---everything a reader could react to without understanding---and destroys only meaning. Value that survives the shuffle is therefore a content-free signal by construction, and run 10b$'$ (Appendix~\ref{sec:failures}) showed such signals arise spontaneously: the reader, which trains by backpropagation on every sampled thought, co-adapts to whatever the writer emits and can manufacture value for a recognizable \emph{shape} of thought. The shuffle control prices out the entire class rather than any one instance, and it doubles as the experiment's key scientific instrument: a thought that passes it while being unreadable to us is a genuine private code carrying anticipation, distinguishable for the first time from register noise. The distillation loss imitates the winning thought on eligible anchors only:
\begin{equation}
    \mathcal{L}_{\mathrm{distill}} \;=\; - \, \frac{\sum_{n \in \mathcal{A}} e_n \log \policy(\best_n \mid \ctx_n)}{\max\!\big(\sum_{n \in \mathcal{A}} e_n , 1\big)},
    \qquad e_n \in \{0,1\} \text{ from Eq.~\eqref{eq:elig}}.
    \label{eq:distill}
\end{equation}

Each gate answers a specific failure (Appendix~\ref{sec:failures}). The speculation margin makes \emph{restating the model's own distribution worthless}: any thought whose content greedy decoding could reproduce has $\gain(\best) \approx \gain(\spec)$ and is discarded, so only content \emph{beyond} the model's NTP distribution is ever imitated. The absolute condition makes \emph{noise worthless}: without it, the relative margin can be won by thoughts that damage prediction less than the greedy guess merely by being ignorable---we observed exactly this degeneracy within 200 steps of our first long-horizon run (Appendix~\ref{sec:failures}). Early in training the two conditions together drive eligibility to near zero, and that is the intended behavior: the policy stays at base fluency, unmoved, until genuinely helpful thoughts appear. The floor $F$ prevents the opposite, self-imitation ratchet: without it, a thought the policy already produces with high probability gets reinforced, becomes more probable, wins again, and the policy collapses onto a single universal thought (observed directly in our run 8; the policy's cross-entropy on its own thoughts fell to zero in ${\sim}100$ steps).

The fraction of anchors failing Eq.~\eqref{eq:elig}---the \emph{discard rate}---is a primary observable. Early in training almost every thought is discarded; the hypothesis under test is that this rate falls as the writer learns.

\subsection{Softening the gate, and a horizon curriculum (runs 16--17)}
\label{sec:soft-old}
\label{sec:softgate}

\paragraph{A dense gate, because the sparse one was empty.} Eq.~\eqref{eq:elig} is a hard conjunction of thresholds. At $k{=}64$ it fired on $0.05\%$ of anchors and for long stretches on \emph{none}: the absolute ``beat silence'' term alone was $\sigma$-equivalent to $0.001$, because inserting \tstart{}\ldots\tend{} perturbs the reader across a $28.6$-token effective window and an untrained reader nets ${\approx}{-}14$ nats from any insertion. Ninety-nine percent of the $2R$ scoring passes we had already paid for were therefore discarded. We replace each hard step by a sigmoid of the \emph{same} margin at temperature $\beta$,
\begin{equation}
e_n \;=\; \mathbb{1}[\text{gate}] \cdot
\sigma\!\Big(\tfrac{\gain - A}{\beta}\Big)\cdot
\sigma\!\Big(\tfrac{(\gain - \gain_{\mathrm{shuf}}) - \delta}{\beta}\Big)\cdot
\sigma\!\Big(\tfrac{F - \gain_{\mathrm{shuf}}}{\beta}\Big),
\label{eq:softelig}
\end{equation}
so every anchor contributes in proportion to how far it clears each bar, and $\beta \to 0$ recovers Eq.~\eqref{eq:elig} exactly. Two properties are load-bearing. The margins remain \emph{absolute}---fixed thresholds and a shuffled minimal pair of the thought itself---so nothing here is relative to a batch statistic; a policy-relative gate is precisely what destroyed run 10a, and the difference between ``relative to the policy'' and ``relative to a control'' is the whole safety margin. And $\beta$ trades density against selectivity, measured rather than assumed: at $\beta{=}1$ the gate carries $4.2\times$ the mass of the binary one while still weighting the top order-borne decile $7.6\times$ the rest, whereas $\beta{=}2$ buys $15\times$ the mass at only $2.7\times$ selectivity---distilling noise. We use $\beta{=}1$ and set $A{=}0$, the literal ``beat silence'' bar: the margin above zero that the hard gate needed to avoid admitting ties is double-counted once a thought at $\gain{=}0$ already receives weight $\tfrac12$.

\paragraph{A curriculum on the horizon, not the geometry.} Appendix~\ref{sec:run16} reports that at a $28.6$-token horizon the reader never learns to use thoughts at all, so the writer has nothing to earn against. But $\gamma$ sets the \emph{effective} horizon independently of $k$: $\sum_j \gamma^{j}$ is $28.6$ tokens at $\gamma{=}0.97$ and $6.7$ at $\gamma{=}0.85$---the latter almost exactly run 15's $k{=}8$ horizon of $7.2$, where the reader demonstrably \emph{does} learn. We therefore anneal $\gamma$ upward during training. Because only the discount weights change and never a shape, no graph is recompiled; the geometry stays $k{=}64$ throughout, so the long-horizon objective is what the run ends on.

\subsection{The learned think-gate and its probes (runs 7--17)}
\label{sec:gate-old}
\label{sec:gate}

On window tokens, the reader uses a learned interpolation between the no-thought and with-thought passes,
\begin{equation}
    \mathrm{logits}^{\mathrm{mix}} = w \cdot \mathrm{logits}^{\mathrm{think}} + (1 - w)\cdot \mathrm{logits}^{\mathrm{base}},
    \qquad
    w = \sigma\big( g_\phi([\,h^{\mathrm{base}} ;\, h^{\mathrm{think}}\,]) \big),
\end{equation}
where $g_\phi$ is a small MLP over hidden states, initialized with a negative bias so $w \approx 0.12$ at the start: early thoughts are noise and must not damage NTP. A similar head appears in Quiet-STaR \citep{zelikman2024quietstar}. Two implementation rules matter. \textbf{(i) The gain uses the pure thought-pass log-probabilities; the reader loss uses the mixed logits.} If the gain used the mix, a closed gate would zero every reward exactly when the writer needs signal most, and the failure would seal itself. \textbf{(ii) The gain is detached}, and gradients flow through the log-probabilities of sampled tokens, never through the sampling.

Left to itself, the gate can learn the degenerate policy of opening for everything (observed in runs 7--8). We therefore inject \emph{probes} at a fraction of update steps: with probability $0.1$ the thought is replaced by an \emph{oracle} (the true upcoming tokens, teacher-forced into the thought slot), and with probability $0.1$ by \emph{random tokens}. The gate's mean weight on oracle probes ($w_{\mathrm{or}}$) and on negative probes ($w_{\mathrm{ng}}$) are calibration observables: a gate that discriminates content shows $w_{\mathrm{or}} \gg w_{\mathrm{ng}}$. Oracle probes double as a live measurement of the \emph{ceiling}: the gain a maximally informative thought delivers (${\approx}{+}32$ nats per discounted window in those runs).

\paragraph{Honesty rail.} The counterfactual in Eq.~\eqref{eq:gain} compares the live model to itself, which admits one exploit: the model can degrade its own \emph{no-thought} predictions so that every thought looks helpful by comparison. A frozen copy $\frozen$ of the initial checkpoint acts as a one-sided referee: an anchor's reward is zeroed when the live no-thought log-likelihood falls more than a margin ($2$ nats/window) below the frozen model's, and a watchdog halts training if plain NTP quality drifts persistently. The frozen model never appears \emph{inside} the reward---an earlier variant that put it there measured live-vs-frozen drift instead of thought effect and destabilized within ${\sim}50$ steps. The referee only looks downward: as the live model surpasses its starting point, the constraint is trivially satisfied and the frozen copy fades to irrelevance.


\section{Appendix: the three-phase programme as planned}
\label{app:programme}

This section is reproduced as it stood before the results of Section~\ref{sec:negative}. Phase A ran (runs 20--21), phase B ran and answered (runs 22--23), and phase C was never run: a budget over \emph{where} to think is only meaningful once a thought is worth something somewhere, which no instrument has yet shown. It is kept because the falsification record is only legible against the plan it falsified.

\subsection{The programme, as written}
\label{sec:programme}

\subsection{The role of reinforcement, stated precisely}
\label{sec:role}
 Our position, sharpened by three falsifications: reinforcement is not the \emph{fundamental} learning mechanism of thinking-in-pretraining---imitation of the true continuation is, because it is dense, grounded, and never taxed the base---but reinforcement is \emph{necessary}, because it is the only estimator that can explore. A supervised objective, however modified, can only push the writer toward targets that can be \emph{named} in advance, and the targets we can name are all drawn from the text itself. But the most valuable thought at an anchor is often not a substring of any future: it is an abstraction, a rule, a disambiguating fact, an intermediate computation---a string whose worth is causal (it changes the reader's predictions) rather than imitative (it matches something). No modified next-token loss can propose such a string; only sampling can stumble on it, and only a counterfactual reward can recognize and retain it. This assigns the two channels their permanent jobs: imitation holds the policy on the manifold of coherent, future-relevant text; reinforcement explores \emph{off} that manifold and keeps whatever measurably pays. Every design below is an instance of this division of labor.

\subsection{Phase A: dense thinking at $L{=}16$}
\label{sec:phaseA}

One billion tokens from the $8.04$B-token vanilla rung, with the procedure of Section~\ref{sec:procedure} exactly as stated: anchors every $64$ tokens ($N{=}14$ per sequence), $\rho = \tfrac14$ supervised, thinking compulsory at the rest with $L_{\min}{=}8$ and $L{=}16$, $R{=}8$ rollouts, raw-gain reward with the shuffle as instrument, $k{=}64$, $\gamma{=}0.97$. Sixteen tokens buy a phrase, not a derivation; the phase is deliberately short-thought so that it is fast (${\sim}27$\,s per $131$k-token step on 64 NeuronCores, Section~\ref{sec:setup}) and so that the only question it must answer is whether a model that is \emph{forced} to commit learns to commit better. Its decisive observables are the fraction of forced thoughts that beat silence, the winner's margin over its own shuffle, and---once instrumented---the order-borne value of a non-selected rollout: in the pilot of Section~\ref{sec:run18} the first rose from $1\%$ to $45\%$ while the second \emph{shrank} from $+3.5$ to $+0.8$ nats, and phase A asks whether an ordered thought's advantage survives once the reader has stopped being hurt by disorder. It is run \emph{from scratch}---the pilot checkpoints carry frozen weights and are not resumed---at learning rate $10^{-5}$, a fine-tuning rate for a converged base given three new loss terms (Section~\ref{sec:run20} is what $5\times10^{-5}$ does).

\subsection{Phase B: reducing supervision}
\label{sec:phaseB}

Half a billion tokens continuing from phase A with the supervised share $\rho$ lowered. The purpose is to learn whether the reinforcement channel can carry the writer once it has a policy worth exploring from, which is the one question the pilots could not ask. We state the risk plainly: every previous attempt to hand the writer from imitation to reinforcement (Appendix~\ref{sec:run13obs}) ended in silence or register, and $\rho = 0$ is that handover under another name. We ran it both ways (Section~\ref{sec:phaseBres}): at $\rho = 0$ the handover failed a fourth time, in $1{,}400$ steps; at $\rho = 0.10$ the writer neither collapses nor improves.

\subsection{Phase C: sparse thinking under a budget}
\label{sec:budget}

Two billion tokens of mid-training at $L{=}64$, $k{=}128$, $T{=}2048$ (the geometry of the pilot in Section~\ref{sec:run19}), in which thoughts become \emph{sparse}. Every earlier design that let the model decide whether to think collapsed to never thinking, because a thought costs tokens and an inert thought costs likelihood while silence costs nothing; Section~\ref{sec:procedure} removed the choice. Phase C returns a choice to the model, but a different one. The number of thoughts per sequence is a fixed budget $B$ of the $N$ anchors; the model chooses \emph{where} they go and never \emph{whether} there are any.

\paragraph{Placement by ranking.} At every anchor the model emits a \tstart{} logit (it always has; the earlier designs thresholded it, and a threshold is exactly what collapses). We rank the $N$ anchors by that logit and open exactly $B$ of them: the top $B$, or---for exploration and for a differentiable selection probability---$B$ drawn without replacement from the softmax over anchors. ``Never think'' is not in the action space, so the collapse is structurally impossible, and the per-token price of a thought no longer competes with the option of paying nothing.

\paragraph{Placement supervised densely by the oracle.} The reward for \emph{content} is the counterfactual gain as before. The signal for \emph{placement} is denser: one additional scoring pass with the true continuation teacher-forced at \emph{every} anchor yields $o_a$, the value a perfect thought would have at anchor $a$---the oracle-regret quantity the earlier designs planned but never built. It is a per-anchor answer to ``is there anything worth knowing here?'' that exists at every step regardless of what the policy wrote, and the \tstart{} logits are trained by a listwise ranking loss toward $\operatorname{softmax}(o_a/\tau)$. Every anchor contributes every step; there is no sparse-reward problem and no score-function variance in learning where to think.

\paragraph{The placement control.} The shuffle taught us to hold a minimal pair for every claim. The minimal pair for placement is \emph{the same $B$ thoughts at $B$ randomly chosen anchors}, scored in one further pass. If the gain at chosen anchors does not exceed the gain at random ones, the model has learned nothing about where to think, and we would know it immediately and unambiguously---as $\gain_{\mathrm{shuf}}$ tells us about content. We regard this control as part of the mechanism, not of its evaluation.

\subsection{What would falsify the programme}
\label{sec:falsify}

Phase A fails if the fraction of forced thoughts that beat silence stops growing before the order-borne value leaves its negative plateau, or if clean NTP drifts by more than $0.5$ nats against the vanilla rung. Phase B fails if the order-borne value falls when $\rho$ is lowered. Phase C fails if chosen placement does not beat random placement, or if think-mode inference does not beat clean-mode inference on held-out text once placement is learned. Across all three, the thinking checkpoint must not lose to its equal-token vanilla rung ($11.5$B tokens) on the zero-shot suite of Section~\ref{sec:evalproto}. Each of these is a measurement we already make; none is a training curve.

\paragraph{The pattern.} Every failure is a shortcut: the objective offered a cheaper way to earn reward than thinking, and the optimization found it---positional invisibility aside, the shortcuts were \emph{copy the future} (run 7), \emph{repeat one safe thought} (run 8), \emph{read the leaked unigrams} (run 8), \emph{be too weird to mislead} (run 10a), \emph{score against a blind referee} (run 10b: anchors with no context, plus selection noise from keeping the best of $m$ rollouts), \emph{teach the judge your handwriting} (run 10b$'$ and again run 11: the reader co-adapts to the writer's register and manufactures value for its shape---the exploit survived a margin-based shuffle control and was closed only by an absolute register floor), and finally---run 12---\emph{no shortcut and no signal at all}: with every channel closed, the honest pass rate of a randomly-initialized thought policy against a mature reader is statistically zero, which indicts the bootstrap, not the gates. The design principles that emerged: for every baseline or gate, ask which \emph{direction} of degeneracy it leaves open, and pair it with its mirror (the floor $F$ with the absolute condition; the speculation margin with the silence bar); every threshold must be calibrated against the measurement noise of the quantity it gates, or the noise itself becomes the winning strategy; and the decisive controls are \emph{minimal pairs}---the shuffle differs from the thought only in order, the speculation rollout only in exploration---because a control that differs in many ways at once leaves room for value that is about none of them. Run 13$'$ supplied the family's terminal member: with every shortcut above closed and the reward finally honest, the cheapest remaining behavior is \emph{not thinking at all}---the gate priced to silence, lengths to the floor, the mode to one two-token stub. A shortcut-free objective does not conjure a capability; it reveals whether one is there, and at this maturity the policy's samples hold nothing the reward can pay for.

\paragraph{Where the project stands, and why nothing is running.} The question the programme opened with---do the policy's own thoughts carry order-borne value---has been answered negatively nine times, and the instruments that answer it have changed twice. Runs 15--18 measured the invariant under designs that let the model decline to think; phase A (run 21) and phase B (runs 22--24) fixed the learning rate, established that the supervised share is load-bearing at $\ge 0.10$, and left the writer plateaued at $-2.2$ nats. Run 25 then produced the project's largest held-out move, $-2.45 \to -1.17$ nats, and run 26 showed what it was: a \emph{pause} of content-free filler tokens, on the same weights, scores $-0.74$ where the written thought scores $-1.17$ (Section~\ref{sec:run26}). Runs 27 and 28 reproduced that ordering on two further independently trained checkpoints under two further reward shapes. The success bar was rewritten accordingly, and it is the bar we now hold ourselves to: \textbf{a thought must beat content-free filler of the same length on the same weights}, because everything below that line is bought compute, not thinking.

Against that bar the probes of Section~\ref{sec:probes2609} located the defect precisely. The reader is not the bottleneck and is not order-blind: shuffling a true $12$-token hint destroys $10.5$ of its $10.7$ nats, so $\mathrm{ob}_0 \approx 0$ is a statement about our writers, not about the reader. The precision ladder puts break-even at roughly $4$ of $12$ positionally-correct tokens, falling to $2$ of $12$ when the uncertain positions are filled with pause rather than context noise (Table~\ref{tab:abst})---a far lower bar than eight runs of failure had suggested. The writer's free-running thought agrees with the true continuation on $4\%$ of tokens (run 25) and, once the supervised target was moved to the immediate continuation, $11\%$ (run 28, Section~\ref{sec:run28}); the \emph{same model, teacher-forced}, is right $44\%$ of the time. \textbf{That gap between free-running and teacher-forced was the whole remaining problem, and Section~\ref{sec:tfslot} has now attributed it.} Teacher-forced from inside the thought slot, the writer averages $0.347$ over positions $1$--$11$, against a break-even of $0.167$ and a free-running $0.019$: the capability is present and above the bar, and the decoding regime alone destroys it. A follow-up on run 29 (Table~\ref{tab:tfslot29}) sharpens this: the position-$0$ collapse was an artefact of run 25's supervised target and vanishes once the writer is supervised on the immediate continuation ($0.047 \to 0.297$), while free-running agreement over positions $1$--$11$ improves $3.4\times$ at an unchanged teacher-forced ceiling and an unchanged \textsc{ntp}---still, at $1.02$ correctly-positioned tokens against the $\approx 2$ required, about half a bar short. This reorders what comes next. Scheduled sampling, which trains the regime we actually sample in rather than the teacher-forced one every run so far has trained, becomes the experiment to run; abstention and phase C stay in reserve, the first because it buys $0.03$--$0.16$ of precision headroom where the free-running deficit is $0.33$, the second because it costs four times as much per step and should not be spent before an $L{=}16$ thought is net positive.

Runs 29 and 30 have since closed the two obvious readings of that gap. Run 29 removed a five-way offset lottery so that the writer is supervised on exactly the tokens the reward scores; it produced the best free-running writer the project has measured and was stopped at step ${\approx}780$ by an $\mathrm{ob}_0$ gate that the abstention ladder has since shown cannot fire at the accuracies it was reaching---a rule we now consider to have been wrong rather than merely strict. Run 30 then applied the textbook remedy for exposure bias, scheduled sampling, and \textbf{falsified it}: it finished below its own matched control on free-running agreement and collapsed the teacher-forced ceiling it was built to exploit from $0.385$ to $0.274$ in three hundred steps (Section~\ref{sec:run30}). Feeding the model its own prefix while keeping the true token as the target asks it to learn a mapping that is not a function, and the residue is noise on shared weights. Run 31 then ran that unglamorous experiment---run 30 with scheduled sampling switched off, which is run 29
plus the aligned register---and it \textbf{failed its first gate in the most informative way available}: at
matched register and matched anchor count its own free-running agreement reads $0.0716$ at step $300$ and
$0.0722$ at step $600$, so three hundred steps moved it by $0.0006$ and run 29's apparent slope was a climb
to the same level rather than a rate of learning (Section~\ref{sec:run31}). The structural alternative---a
non-autoregressive slot, with no prefix for errors to propagate through---was measured before it could be run
and came out \emph{below} free-running autoregression on both relevant checkpoints ($0.020$ and $0.018$ over
positions $1$--$11$, against $0.071$ and $0.069$); we read that as a lower bound on an untrained regime
rather than a refutation, but it is not the escape. Exposure bias, decoding order and optimization time have
now each had a run or a probe of their own, and the free-running writer sits in the same place after all of
them. \textbf{We therefore stop trying to raise the writer's accuracy and start reducing what its errors
cost.} Run 32 supervised the writer to speak only where the next token is forecastable and to emit
content-free filler everywhere else---the interleaved-pause format that the abstention ladder measured as
readable, and which drops break-even from roughly four correctly-placed tokens of twelve to two
(Section~\ref{sec:run32}). It stopped the writer from harming without making it help: own-minus-filler
settled at $-0.130 \pm 0.033$ and stayed there. Run 33 attacked the term that decomposition says is five
to six times larger---the price of splicing the block in at all---and \textbf{it was stopped at step $899$
when the mechanism reversed}: the block's price fell to $-0.551$ by step $400$ and then rose again to
$-0.664$, a quarter of the available headroom rather than the two-thirds its gate required
(Section~\ref{sec:run33}). Reading its value gate exposed a defect that retires a number we had reported:
on an abstaining lineage the model's greedy thought \emph{is} the filler control---space tokens and a
closing marker---so own-minus-filler on that instrument measures length, and at matched length run 32 has
no measurable content effect at all. \textbf{Run 34 asked the question that exposes---is a token the model chooses to write worth more, to the
same model reading it, than leaving the position empty?---and answered it no} (Section~\ref{sec:run34}).
Run 32 reached its best value by ceasing to speak---filler at $88\%$ of positions---so run 34 removed the
loss term that made silence a supervised action while keeping the format, and its gates required the writer
to speak before any value reading was accepted. It spoke: the filler rate fell to $0.043$, its opener and
its teacher-forced ceiling recovered, and its free-running token agreement rose above run 32's. Its value
fell with it, to $-0.520 \pm 0.067$ at a four-token prefix, below even the unabstaining control it started
from. Across the three checkpoints own-minus-filler is a function of the rate at which the writer emits a
non-blank token and not of how often that token is right, which retires run 32's apparent value as a
selection effect of silence. That is the form in which we register the negative result: at this scale a
token the model chooses to write is worth less to it than a blank, and the cost scales with how often it
chooses to write one. The benchmarks of Section~\ref{sec:bench} have now been run on that final checkpoint, and they close the result rather than qualify it: the five-task discrimination gain that run 21 showed is gone ($+0.12$ points, $p = 0.91$), a thought at inference costs $1.4$ macro points against the same weights in clean mode ($p = 4\times10^{-4}$), and the thought being scored is $258$ distinct strings over $4{,}000$ examples---a register, not a forecast. One line in them is encouraging and it is the same one: making the writer speak is downstream-free. Paired against run 34's own initialisation the whole benchmark suite moves by macro $-0.4$ ($p = 0.47$ on the pre-registered pool), so the capability the objective has cost was spent earlier, on recalibrating the reader, and not on the speech. What is missing is not permission to speak; it is anything worth saying.

No run is live as we write this, and that is a result rather than a pause. Each axis the programme opened has been closed by a measurement and not by exhaustion: writer accuracy by runs 28, 30 and 31 and the parallel-slot probe, which put four different levers against the same flat floor; the decoding regime by run 30's falsification; the choice of \emph{where} to speak by run 32 for frequency and, without spending a run at all, by the count-matched ceiling probes for confidence and its opposite; the price of the block itself by run 33, whose mechanism reversed at step $400$; and speaking against abstaining by run 34, which found value tracking volume and not correctness. Phase C is gated on an $L{=}16$ thought being net positive on held-out text, which has not happened once in thirty-four runs. We would rather record an idle node than improvise a thirty-fifth run onto an axis a probe has already closed, which is the failure mode the pre-registered gates in this paper exist to prevent.
