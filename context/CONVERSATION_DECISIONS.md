# Decisions carried into this handoff

**Explicit owner goal:** Learn useful self-generated computation; then investigate
earlier onset and efficiency. Preserve social/safety ambitions as subsequent
applications. A modest NTP cost may be acceptable for real downstream value.

**Weekend recommendation accepted as the implementation basis:** one mature-model
C/R pair, actual released weights, signed thought-policy update, generous thought
budget, separate training/inference evaluations, then replication if time permits.
The latest request is packaging and continuation—not permission to silently
change that experimental design while adding code.

**Operational request:** one downloadable repo to put on the existing instance,
with sufficient context for Codex to keep working. No separate source upload
should be needed for the bundled code/context. Actual weights/corpus/credentials
must be acquired or located on the instance.

**Constraints:** no Bedrock; no unapproved cloud resource provisioning; no paper
rewrite during primary experimentation; preserve the working accelerator stack;
no claim of hardware validation based on CPU tests.

**Not settled:** actual local environment, surviving checkpoints, data location,
resolved model/data commits, actual throughput, terminal steps chosen from timing,
capacity cutoff, approved backup path, and whether the recipe produces a gain.
These must not be filled with invented values.
