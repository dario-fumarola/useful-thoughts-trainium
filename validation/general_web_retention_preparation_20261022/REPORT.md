# Fixed general-web retention diagnostic: preparation

A separate 1,024-document educational English-web cohort is ready. It will measure whether the qualified FineMath baseline and matched learning models retain prediction quality outside their mathematical source frame. It does not change their original source allocations, checkpoint selection, confirmation endpoint or decisions.

The pinned source is [FineWeb-Edu](https://huggingface.co/datasets/HuggingFaceFW/fineweb-edu), revision `87f09149ef4734204d70ed1d046ddc9ca3f2b8f9`, file `sample/10BT/000_00000.parquet`, SHA256 `b1ba7b2ce4cb5ea6ef42dca40263eabb85f37700d01693a68e9b30a31d78e871`. It is English educational web text, not all language or a corpus proven absent from B0 pretraining.

The fixed first 32,768 records provide 18,239 eligible unique documents: 13,775 are too short, 377 overlap known mathematical pages/content, and 377 repeat a page or content. Exclusions cover 1,928,315 canonical pages and 2,347,742 known content identities. Fixed identity hashes choose 1,024 sources and one intact 528-token window per source, without arithmetic filtering or model scores. Independent reconstruction verifies every selected record and token, selection order and exclusion. No failed row is replaced. Source preparation takes 85.56 seconds; independent checking takes 23.07 seconds. Both make zero model calls.

The diagnostic reuses the byte-bound original native likelihood worker with eight ranks and microbatch four, predicting all 527 shifted original tokens. The new wrapper checks the distinct cohort, full source identity, independent receipt, checkpoint hashes and all required terminal models. All four ordinary-baseline checkpoints already froze before this source plan. Every one of the six scaffold terminals must freeze before its diagnostic evaluation. The generic supervisor retains its original default behavior and explicitly allows this reviewed evaluator. The runtime floor stays 512 GiB; a separately explicit 672 GiB prelaunch reserve leaves staging headroom. All 2,058 CPU tests, smoke and compilation pass, including 23 new source/model/entrypoint boundary checks.

The additional hard ceiling is **1.5 assigned chip-hours**, on one existing two-chip pair at a time; source/output storage is bounded at 3 GiB and CPU preparation at 30 minutes. There is no new training or teacher call. Assigned reservations are not whole-node billing.
