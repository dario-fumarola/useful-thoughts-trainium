Every public asset was downloaded anonymously, hash-checked and reconstructed with the standalone decoder; all original BF16 tensor values match exactly. Each restored model also loads through standard Hugging Face and returns finite logits in a CPU forward check. These are artifact checks, not additional task scores.

## Restore and use

Get the exact **Qwen/Qwen3-1.7B-Base** snapshot at revision **ea980cb0a6c2ae4b936e82123acc929f1cec04c1**, one model delta above, and the [standalone restore tools](https://github.com/dario-fumarola/useful-thoughts-trainium/releases/download/trained-model-deltas-20261022/RESTORE_TOOLS.zip). Extract the tools and run:

```bash
USE_TORCH_XLA=0 python restore_model_delta.py \
  --base-dir /path/to/pinned-Qwen3-1.7B-Base \
  --delta /path/to/model-name.npz \
  --out /path/to/new-model-directory
```

The new directory contains exact BF16 safetensors weights, configuration, tokenizer, provenance and the upstream Apache 2.0 license. Use a base-model completion interface. These checkpoints are not instruction-tuned chat models. The download is lossless compression rather than quantization; original optimizer state is not included. Exact native training resumption uses the retained native snapshots.

## What the results establish

The ordinary reference improves fresh FineMath prediction but regresses on a separate English panel. Both mixed-source orders improve on B0 in the two declared fresh domains and beat that reference on the declared 50/50 target; the all-math reference remains stronger on Math alone. The computation auxiliary loses to matched ordinary training in both orders. All models use the same mature pretrained starting checkpoint and short continued training; these findings do not establish autonomous computation discovery or broad language improvement.
