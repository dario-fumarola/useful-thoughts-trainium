# Included original material

Selected files from the uploaded `ema-trainium-pre-thinking (1).zip`, preserved
byte-for-byte unless a path-only safety rename is recorded. The complete included
and excluded inventories and original archive checksums are in
`../context/provenance.json`.

Included: all current `.py` source under pre-training, current benchmark code,
relevant design documents, current manuscript TeX/Bib/style sources, journal,
runbook, current status, postmortem, and selected numerical probe outputs/scripts.
Excluded: redundant backups, old active launchers/watchdogs, cached benchmark
samples, result duplicates, binary figures, and unrelated logs. One provenance
launcher is kept as `.sh.historical.txt`, never as an active launcher.

No original trained weights or raw training-token corpus were present in the
packaged source selection. The older standalone manuscript sources are under
`context/historical_manuscript/`. Nothing in this directory establishes the
current instance, cloud reservation, credentials, checkpoint survival, or safety.

The original source has known bugs. The narrow target repair is in `patches/`
and tested separately; it has not been silently applied to this preserved copy.

Manuscripts are included as textual context. Figure binaries and redundant build
artifacts are omitted; this is not a complete paper-compilation bundle.
